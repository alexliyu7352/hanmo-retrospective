# 六角野战原画交接

四张原画由内置 imagegen 生成，原始 PNG 保留生成像素。山谷为装饰背景；六角格、实际通行地形、退路、射界、文字和军队人数全部由引擎绘制。三个透明小部队图表示部队类型，不以画中人数代替真实编制。

`manifest.json` 记录建议注册 ID、尺寸及 SHA-256；它是本次素材交接表，生产入口仍以 `game/data/presentation.json` 为唯一清单。根层需把 `battlefields.visual_tag` 注册为背景 ID，把 `troop_types.battle_portrait_kind` 注册为部队肖像 ID。UI 不内置图片路径。

`prompts.json` 保存首次生成提示与最终弓兵修订提示。首次弓兵有晕染，第二次产生棋盘背景，第三次仍有晕染，均未作为最终资源使用；最终弓兵以步卒图为参照重新生成并保留真实 RGBA 透明边缘。步卒和骑兵也是 RGBA，山谷为 RGB。未用图像脚本修饰图片，也未将原画当作游戏运行截图。

GUI 验证夹具只在进程内根据交接表装入待注册图片，正式清单、作者包、世界存档和军营入口由集成方验证。生产使用的图片缩小时启用 mipmap，减少细节闪烁。
