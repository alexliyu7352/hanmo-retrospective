96×128像素仅用于验证真分层、child/adult独立坐标、独立衣服、语义选件、双专绘与CPU像素合成。儿童有独立头身坐标和衣服；不是成人缩小。不是最终美术、历史真实相貌或视觉发行验收。

这些文件只被隔离测试清单引用，不注册进生产 `game/data/presentation.json`。运行生成器可重建相同图片与几何声明。
