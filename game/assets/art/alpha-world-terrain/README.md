# 世界地形：原画与可运行样本

最终底图：`regional-terrain.png`，1620×971 RGB，内置 imagegen 生成后两次编辑，保留原始像素；没有裁切、缩放、调色或程序绘制替代。它是背景素材，不是游戏截图。来源、提示词、各版本用途和 SHA256 见 manifest.json。

匹配定义：`logic-map.fixture.json`，1000×600 世界坐标、cell_size=20、从左至右从上至下扁平1500格。源函数在隔离分支 game/tests/test_world_terrain.gd 的 regional_fixture()；主工程负责作为作者数据落盘并注册美术。主渡口中点[500,290]、北桥[490,50]、北山关[190,110]；青川入口建议[190,430]、东里[830,290]。显示时完整映射画幅，不能裁掉图边再使用原坐标。

原画实际位置与最初提示有偏差，最终定义按真实画面校准。地形边缘采用20单位格距分类，画中的树叶、岩石和水岸细节不是精确碰撞遮罩；不能将其描述成像素级一致。关键河道、山脊、山道、渡口、北桥和绕行路径已有对应逻辑，地图界面不必绘制内部网格。

备用路：西侧入口沿西山道越关，走北侧道路过北桥，再从东北山地西侧的弯曲山脚路南下，连接东侧主路。关闭 crossing.main 后查询改走这条路；渡口与北桥皆闭，或渡口与山关皆闭，返回 NoRoute。旗标true为关闭；关闭是整格封锁，船也不能穿过被旗标封锁的格。未封锁的桥/渡口仍保留水路，boat不能从此变成陆行。

真实 Godot 查询示例见 route-examples.json：步行主路消耗8084，军团主路12655，封主渡口后步行绕北桥10716，中央水路4720。这些是通行消耗单位，不是钱或半日；根层使用作者的每半日预算换算时间与费用。途中改道与返程保留[380,270]等实际任意合法位置，不送回据点。

纯查询接口：validate_map(map)、point_valid(map,point,mode='foot',flags={})、segment_cost(map,from,to,mode='foot',flags={})、plan(map,from,to,mode='foot',flags={})。path包含points、segment_costs、cost，整数起止点不被吸附到格心；输入不变。默认foot/army须桥或渡口过水，mountain禁行，pass放行；作者可为foot.mountain显式配置正成本允许翻山。
