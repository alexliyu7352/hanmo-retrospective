# 汉末行记｜卡片、门派与盗贼水上势力设计补充｜2026-10-01整体修订

初稿：2026-09-11；整体修订：2026-10-01。上位：当前产品定位（未公开）与原位更新的总体设计v0.2。沿用同一Godot工程；当前Alpha已有部分人物修炼、战争与基业能力，但七类卡片和完整门派/盗贼/水上组织不能据此标为全部实现。当前事实见GOAL_PROGRESS。

## 1. 本次明确的目标

用户要求保留太阁5中大量卡片形成的玩法，并根据汉末题材实质调整组织人生：忍者体系改为可学习武功、心法的门派体系，包含门派战争和统一武林；盗贼、海盗保留其可玩的机制并按实际时代与地域调整。

卡片、门派、盗贼和水上势力均进入完整产品范围。旧稿的48张卡片是区域样本预算，固定“八条人生／四类组织”不再限制新的完整目标。村庄、庄园、坞堡、公职、部曲与幕府可以并存的既定方向继续有效。

以下卡片分类、组织循环、统一判定和验收情景是将用户要求落地的设计方案，具体数值与内容数量另行细化。本次根据实际三作视频核验（未公开）整体修订文档，不修改产品代码、不追加新的通过结论。

## 2. 原作参考与汉末化方式

官方手册区分主角、秘技、称号、合战、名胜和其他六种卡；取得卡片连接人物亲近、修业、流派学习和探索，卡片具有实际作用。图鉴记录与当前存档中的效力也有区别。[太阁5 DX官方手册：收集卡片](https://www.gamecity.com.tw/manual/taikou5dx/sc/3400.html)

忍者生活包含组织任务、专属学习、管理据点、指派属下、攻击敌方据点、独立和选择支持的政治势力。本项目借其专属学习、职事、指派、资源与组织战争的结构理解需求；汉末门派事务、武学传承、山门经营和武林竞争必须重新设计其社会理由和日常生活，不能逐项改名照搬。[官方手册：忍者的生活](https://www.gamecity.com.tw/manual/taikou5dx/sc/5200.html)

水军生活包含共同执行任务、技能与船相关卡片、管理水军据点、攻守、独立和争夺海域。本项目在江河、湖泊与近海地理中表达相应生计及武装活动。[官方手册：水军的生活](https://www.gamecity.com.tw/manual/taikou5dx/sc/5300.html)

原作正式势力系职业为武士、忍者、水军和商人。本项目根据用户要求扩展可完整经营的盗贼人生，不宣称原作另有同等完整的第五种盗贼职业。[官方手册：游戏流程](https://www.gamecity.com.tw/manual/taikou5dx/sc/1200.html)

| 原作经验或本次需求 | 本项目的转化 | 保留的实质 |
|---|---|---|
| 忍者众、忍之里、头目与专有忍术 | 门派、山门及分支、掌门与门人、武功与心法 | 组织晋升、专属学习、人才指派、资源经营、战争、独立与势力往来 |
| 剑豪、流派与授徒 | 个人武学修炼与传授，可与门派身份重叠 | 个人武学成就与组织统治各有目标，武力高不会自动成为掌门 |
| 盗贼机制 | 独行盗贼、聚众山寨及地方劫掠势力 | 取利、分配、据点、生存、追捕、竞争与可选择的身份转换 |
| 水军与海上势力 | 江贼、湖盗、沿海海盗、护航船帮及正规水军 | 船只、船员、水路、港寨、补给、战斗、控制范围和政治关系 |
| 大量卡片 | 覆盖各类人生、修业和探索的可扩展卡片体系 | 获取过程有内容，学会或获得后能改变能力、资格、信息或人生选择 |

门派、心法和统一武林是用户明确要求的架空武学设定，具体组织名称与谱系作汉末背景下的原创设计。汉末历史环境与原创武林分别标明：城邑、乡里、豪族、庄园坞堡、部曲、交通和官府提供生活约束，门派可以有真正的武学传承、山门、组织战争及统一目标。历史核对用于校准背景、资源、称谓和地理，不据此把门派削成只有家学/庄园的玩法。

设计每个组织时，必须回答其宗旨、何人为何加入、由谁传授、如何谋生/供养、与周边居民和官府何种关系、职事如何任免、据点为何可争、首领离任后怎样延续。不能只填“忍者→门人、忍术→心法、忍之里→山门”的对应表；也不直接移入龙胤宣传片中的后世著名门派名称。对应表仅说明参考来源，不是内容模板。

## 3. 卡片是贯穿人生的核心机制

### 3.1 本项目的卡片分类

在旧稿六类基础上增加心法类别，并扩展各类覆盖范围。下表是本项目分类，与原作的六种分类分别说明。

| 类别 | 主要来源 | 实际用途与边界 |
|---|---|---|
| 人物卡 | 交往、共同经历及对应人物条件 | 解锁不同人物和开局处境；解锁不复制其上局财产，也不使当前NPC自动加入玩家 |
| 技艺卡 | 修业、实践、师承、职业经历 | 开放或改善经营、交涉、医工、运输、侦察与水上活动；效果必须指向已实现行动 |
| 武功／秘技卡 | 师门传授、合格典籍、切磋与领悟 | 提供有武器、距离、朝向、资源和掌握条件的个人能力 |
| 心法卡 | 师承、研习与修炼 | 提供可修炼的基础能力体系及与武功的配合；掌握程度、修习配置和适用范围参与实际结算 |
| 战法卡 | 军事、水上及组织作战经历和训练 | 对获授权的部队或组织作战单位生效；有兵种、地形和资源条件，不赋予额外指挥权 |
| 称号卡 | 成就、社会评价、职业或武学里程碑 | 记录并影响相应评价或资格；头衔本身不替代真实官职、掌门任命和组织认可 |
| 见闻卡 | 名胜、旅行、人物与世界经历 | 记录探索成果，提供相应知识或学习线索；不能泄露尚未知晓的人物位置和势力状态 |

大量卡片的内容来源应覆盖仕途、商旅、散人、门派、盗贼、水上生活与各类求道。每个门派的武功、心法、学习条件和理念应形成区别，航行、经营和非战斗角色也须有值得收集和使用的成果。数量随有效内容扩展，不能以同效果换名或空白图标计作完成。

### 3.2 获得、修炼、使用与收集

日常循环为：获得线索 → 找到人物、场所或事件来源 → 满足条件并完成实际行为 → 获得卡片或对应本领 → 在适用行动中使用或继续修炼 → 留下可保存的成长记录。

卡片按类型采用不同规则：见闻与称号可以在事实成立时取得；武功、心法需要相应学习及掌握状态。持有实体秘籍只提供研习来源，不能立即按精通程度施展；得到传授后，修炼进度和配置继续影响能力。典籍物品、所学本领和卡片图鉴分别记录。

同一能力可有多个符合设定的来源，例如不同教师、典籍或实践领悟，记录第一次取得与后续修炼来源。稀有卡可以有当局错过的机会，基础生计和核心成长应有替代渠道；不能因唯一教师离世而锁死所有可继续的生活。

主动武功进入当前可用指令，心法和被动技艺按其配置生效，战法遵守实际控制权。发动仍需满足体力或气势、武器、范围、状态与掌握条件；不加入随机抽到卡才能行动的牌组规则。

同一卡片重复取得不重复叠加同一被动收益；继续修炼由明确的成长规则处理。取得卡、授予能力、记录成就和全局发现需要相互一致，读档、重新交谈或回看图鉴不重复领奖。

### 3.3 图鉴、新周目与世代传承

跨局图鉴记录曾经取得的卡和已解锁开局；当前人物实际掌握什么，属于本局人物状态。图鉴可以呈现已获得内容及合理线索，但没有获得的能力不能由收藏页面直接调用。

世代传承在同一世界中处理教师、典籍、修炼条件与继任者的学习。家族或门派保存的知识可以成为继任者的成长来源；前代的全部修为、私人称号效果和他人信任不会因全局收藏完成而自动复制。

## 4. 门派：从个人入门到组织竞争

### 4.1 门派成长与日常事务

个人可从求学或加入门派开始，经过修炼、贡献、考核和人际关系取得更深传承与职责，进而主持分支、继任掌门或自立门户。具体层级称谓由门派定义，不固定照搬忍者官阶。

门派具备宗旨、传承武学、学习资格、真实门人、山门与分支、资源、职事、外部关系和领袖继任规则。武功、心法、门人之间的师承与竞争共同决定学习经历，贡献值只是一项条件。

门派事务可以包括授徒、比试、护送、探听、营救、筹粮、访学和守卫。旧豪侠委托可继续复用，但不同门派依据理念与利益提供不同事务，玩家可接受、拒绝、协商或离开，并承担相应组织后果。

学艺与师承不自动占用主要公职契约。门派职事的实际责任与公职、私人基业及其他承诺共同判断，不能用一个职业标签禁止官员习武、拥有师门或经营家产。建立自己的门派也需要真实地点、人才与资源。

### 4.2 门派战争

门派可以结盟、争夺资源、袭击或守卫据点、援助盟友、兼并、归附和分裂。战争由组织目标与关系触发，参战者、领队、供给、行程、伤亡及占领来自同一世界。

小规模切磋、追击、护卫与营救使用个人战；有实际组织队伍的交战使用相应战术规则；山门或分支攻防使用可配置的据点拓扑。共用既有战斗会话、位置与结果回写约定，保留各战斗尺度的区别。

战后分别处理领袖存续、门人去留、据点控制、藏书与物资、师承和敌对关系。击败掌门个人、攻破一处山门、使另一门派归附是不同事实，不能用一次单挑直接改写全部门派归属。

### 4.3 统一武林

统一武林是可选的组织后期目标。剧本明确参与该竞争的门派与地域范围；达成时，这一范围内的门派均已受玩家组织统辖，或加入承认其共同号令的有效盟约，仍有独立抗拒的竞争方时不能宣布统一。

统一可以通过战争兼并、归附和获得认可的盟约等方式实现。名望或武学大会可以帮助建立认可，但只有称号、赢得一次大会或打败某一名高手不足以达成组织统一。

达成后记录一次相应范围的里程碑，并允许继续经营、修炼、任官或传承；此后关系仍会变化。区域样本只称区域武林成果，不能宣称完整世界统一。武林统一与政治势力统一各自判断，也不强迫其他人生走向这一目标。

## 5. 盗贼与山寨人生

玩家可独行，也可投伙或聚众，从个人生存发展到组织山寨。主要循环为：获取消息与资源 → 选择行动 → 处理所得和损失 → 分配与供养成员 → 应对受害方、地方官府和其他组织 → 扩张、迁移或改变身份。

盗窃、劫掠、索取过路财物、袭扰和争夺据点作为游戏内行为提供收益与风险。所得须来自实际人物、货物或仓储；销赃、分配和开支也有真实对象与库存。已有受害记录、传播和追捕决定后果，不能靠切换一个身份清空旧事。

首领需要处理驻地、防御、生计、部众供养、分配公平与内部关系。持续掠夺会影响当地生产、行旅和可获取的资源，官府及竞争势力使用其实际可用力量作出反应。

可以选择保护乡里、与豪族合作、维持掠夺、接受招抚、投军或争夺更大的地方权力。招安不是全部成长和结局的强制条件；未选择招安时仍须有完整的经营、竞争与生存内容。豪侠也可作为其中的行为立场或独立散人生活，不将所有盗贼任务改成救人护送。

## 6. 江贼、湖盗、海盗与水上势力

按实际剧本区分江河、湖泊和沿海活动区域。船只通行能力、船员、水手技艺、载重、泊地、风候或水情、补给及修缮影响路线与行动；早期内容可先覆盖局部水域，完整目标保留沿海海盗。

共同基础是船队和水上据点。玩家可以运输与护航，也可以劫船、劫货、争夺泊地、封锁航路和攻守水寨。水军、船帮与盗贼的政治身份和当前行为分别记录，不能仅因拥有船只就自动视为海盗或正规水军。

俘获船只、货物和人员需要实际战斗或交涉结果，接管后还要处理损伤、船员、承载和供给。登船近战与船队作战按相应尺度接入现有战斗体系，不能凭船只总价直接宣布胜利。

后期可以独立建立水上组织、争夺重要航路与水寨、结盟归附或受编为正规水军。水域霸权按实际据点控制、通航或封锁能力与组织认可判断，跑完几趟贸易合同仅是经营阶段成果。

## 7. 历史依据与创作边界

《三国志·张燕传》记聚众、联合其他首领及后来取得官号、依附政治势力等变化，可为山地武装的组织成长和身份转化提供参考；不将所有起事、宗教组织和地方武装简单归为同一种盗贼。[《三国志》卷八·张燕](https://zh.wikisource.org/zh-hans/三國志/卷08#张燕)

《三国志·孙坚传》记钱唐附近海贼劫取商旅财物、阻碍船行的事例，支持将沿海劫掠与交通、生计联系起来。具体港寨、船型、范围和历史人物活动仍需按剧本核对。[《三国志》卷四十六·孙坚](https://zh.wikisource.org/zh-hans/三國志/卷46#孙坚)

这些史料支持背景与关系，不证明本项目的功法、心法、门派谱系、武林盟约或游戏公式属于真实汉末制度。09-11初稿只读取文字资料；本次已有三作指定范围的视频/画面核验，详细来源与边界另存参考记录。它仍不等于本作视觉已验收，也不增加未观察到的史实或游戏公式。

## 8. 与已有世界、经营和传承的连接

卡片能力引用对应人物的实际成长；门派、山寨、水上组织及官府复用组织成员、职事、关系、资源、行动和战争边界。表现图像与卡面由统一表现清单管理，不在UI设置第二份可用能力或组织白名单。

门人、部曲、船员和庄园劳力使用真实成员或明确的聚合人员账。同一人可以兼有社会身份，但同一时刻不能作为两支出征队伍的战力，又继续在庄园劳动；招募、训练、调动和战后返回均有来源。

学习、窃取典籍、攻占山门和领袖继任分别更新知识、物品、地点控制与职事。易主不会把所有在场者的武学瞬间复制给获胜者，继任也不自动继承全部私人忠诚。保存恢复要覆盖这些变化，且与既有世界处在同一存档。

私产、公库与组织物资可按实际规则流转。门派、山寨和水上组织可以支持或对抗政治势力，官职授权仍按真实职责处理；自家门人或部曲不会因打开官署界面自动成为全部公军。

## 9. 后续体验验收

以下是持续有效的完整范围验收要求，不是通过记录；当前Alpha局部能力需按CO逐项核对，不能由一次学习或一场军战代替完整卡片与组织人生。

| 编号 | 玩家行为 | 应能验证的结果 |
|---|---|---|
| CO01 | 通过交游、生活实践、修炼与探索取得不同卡片 | 来源和条件可追溯，非战斗卡也有实际用途或见闻价值，重复领取不叠加奖励 |
| CO02 | 取得武功与心法并修炼、配置、实战 | 掌握程度和配合影响实际能力；持有秘籍或图鉴记录不能直接按精通效果调用 |
| CO03 | 重开新人生或在原世界传承 | 图鉴与解锁保留其用途，本人掌握和继任者学习按各自规则处理 |
| CO04 | 在门派成长并主持一处据点 | 职事、门人、资源和指派权限真实变化，称号卡不替代组织任命 |
| CO05 | 从同一地图发动一场门派冲突 | 行军、占用、供给、战斗、损失及战后恢复成立；单挑获胜不自动兼并整派 |
| CO06 | 通过兼并或有效盟约统一指定范围武林 | 依据实际组织状态判定，允许继续游玩，不要求同时统一政治势力 |
| CO07 | 以盗贼身份获得、分配和使用战利品 | 资源从实际对象转移，部众生计与受害方反应变化；拒绝招安仍可持续游玩 |
| CO08 | 以水上势力劫获货船或攻守水寨 | 船员、船损、货物、泊地和控制权正确处理，与普通运输、护航有所区别 |
| CO09 | 任官同时维持庄园、师门与私属力量 | 身份可以并存，职责与资源往来有后果，人员不分身、兵力不重复计算 |
| CO10 | 保存并重启尚未结算完的学习、战争或继任过程 | 恢复实际阶段，不复制卡片、秘籍、船只、兵员、关系或战利品 |
| CO11 | 用同一编辑器新增另一门派、卡片和水寨内容 | 可配置既有机制并进入同一游戏；未知效果先报错，不用空字段冒称机制已实现 |

## 10. 当前缺口与接续范围

09-11的0.6.1审计确认当时没有卡片、门派和战争能力，这段事实不能继续当作当前状态。当前Alpha已有武功/心法的最小学习、修炼、使用和传授，以及战争、庄园、公私力量和继任的相关基础；这些成果不是七类卡片完整收藏、所有门派职事/战争/统一、盗贼山寨及完整水上人生的替代。

当前接续先把已有机制形成连续、可辨认的人物生活与视觉样板，并以同一人物的师承、实践、卡片、家业和组织关系证明相互作用。再按依赖补足真正的组织成员、职责、据点、资源和战争内容；各阶段都保留学习/经营/社会/传承联系、保存恢复和同一工坊第二配置复用。不能继续把所有新增需求排在M2之后，也不能靠批量生成卡面或改职业名宣称完成。

具体实施状态和下一动作由GOAL_PROGRESS维护；完整目标、CO01—CO11和既有数量预算的历史身份保留在这里。

本补充修订旧稿以豪侠委托承接忍者体系、水上生计偏重运输护航而盗贼与海盗道路不完整的问题，并解除固定八种人生与六类卡片的完整范围限制。既有原型参数、48张卡片样例和地方生活内容仍可作为开发材料；其数量与过去的测试不代表新增机制已完成。


## 11. 组织成长的可见过程与UI边界

从个人求学到组织领袖应发生可见的生活变化：认识师父与同门、取得学习资格、练习和比试、承担有对象的职事、管理真实门人、委任驻地负责人、筹措供给、营造或守护据点、处理盟友与竞争者。贡献和声望可以是条件，不能替代这些实际经历或组织认可。

组织结构图可以采用人物肖像、职位与空缺、分支及驻地来说明权责；资源详单与任命列表同样允许。已核验龙胤组织岗位/任命营造画面支持这类信息组织参考，不能证明本作所需的全部模拟规则。查看空位不生成成员，点击营造不即时完成建筑，漂亮图谱不使掌门权力或师承事实自动成立。

山门、庄园、军营、山寨和水寨各有可辨识场景、在场人物和活动；管理详单不永久遮掉地点身份。通过人/地点/合法通信进入实际事务，回到场景时能看到人员离返、设施进展、练功/劳动或战后变化。个人档案、手记、行囊和图鉴可独立查阅，不强制无意义寒暄；也不以便利为由越过地点、消息和授权。

门派和人物的视觉语言属于统一原创汉末2D绘景体系，身份与装备一致，卡片按类别呈现来源、用途、掌握和收藏。完整门派、盗贼与水上玩法仍各有自身特色；不用统一发光卡面、武器决定通用人物、静态背景加按钮墙代替差异。具体屏幕状态与VIS门槛见09，场所人物原则见11，动作和战争表现见05。

## 12. 跨系统体验样本与防遗漏

一个小区域可同时承载散人学艺/传授、门派职事与据点、庄园经营与部曲、公职借调及合法继任；样本是联合验证，不要求玩家按固定次序完成。进一步分别用山寨的实际劫获/分配和水寨的船队/俘获内容证明它们不能被护送或运输合同代替。

每条样本检查来源→条件→投入→执行→结果→社会反馈→继续生活，保留拒绝、失败、退出和恢复路径。收集卡片不授予无条件组织权力；个人比武不直接吞并门派；武林统一与政治统一分别判断；继任不复制修为和私人忠诚。源于太阁的生活模式、汉末原创武林和所选补充参照共同服务这一世界，不建立三个彼此分离的小游戏。

完整目标与Alpha、规则与视觉、参考观察与本作设计分别报告；CO01—CO11及原GDD/详细设计验收均不被替换或减少。本次新增的是文档约束，仍需在同一引擎真实运行、第二配置和保存恢复中举证。
