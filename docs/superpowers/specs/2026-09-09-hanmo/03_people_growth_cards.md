## 3.1 人物结构与属性

人物定义与局内状态分离。定义包含稳定ID、显示文本键、历史/原创标签、固定外貌配置或受约束生成配置、头像资源关联、初始属性、性格和剧本出处；局内状态保存实际外貌特征、生成版本与seed，以及属性成长、技能经验、体力疲劳、位置、职务、钱包/物品、关系、行动、卡片及经历。外貌字段为本次待实现合同，来源、年龄及保存细则见§3.25与08§8.19，不能只凭头像路径或seed在读档时重新生成人物。改名不改变ID。历史标签需要出处字段，原创角色不能包装成真实人物。

五属性为统率、武力、智谋、政务、魅力，基础1—100。P1不通过普通重复修业无限增加属性；每属性一生最多+5点永久成长，来自五个不同的对应里程碑，每个+1。修业主要增长技艺。装备和伤病的临时修正单列，实际值`clamp(基础+成长+临时,1,110)`，不改写基础。完整目标的先天禀赋另见§3.14：可遗传和有限强化，但不是父母属性/技能的复制，也不自行突破本节上限；出生初始潜力与成长兑现须分开。

标准自建人物：五项从40开始，额外100点，最终总和300；单项20—85，降低属性按1:1返还点数；10项技能共4级初始点，单项不超过2。选择专长不能再免费叠加点数。旧P1自建年龄18—60是开局预算；完整生命周期中年龄、成长与继任资格按已定义规则生效，不能继续把生日解释为永不影响机制的纯叙事字段。出生年份由剧本锚点和年龄换算，不制造未核验历史人物。

自由创建允许单机自行调参，记录`creation_mode=free`，不禁用主要玩法，不加入服务器验证。跨局图鉴区分自由解锁标记，但不处罚玩家。

## 3.2 技能等级与经验

累计经验门槛：0级0、1级100、2级300、3级650、4级1200。等级按最高已达到门槛派生，经验上限1200；不另外维护可与经验矛盾的可写等级。一次奖励超过门槛可连续升级；同一奖励实例只生效一次。

| P1技能 | 属性辅助 | 起作用的地方 |
|---|---|---|
| 步战 | 统率 | 步兵攻防与训练 |
| 骑战 | 统率 | 骑兵机动、战法资格 |
| 弓弩 | 武力/统率按战斗类型 | 个人弓术、弓弩兵训练 |
| 武艺 | 武力 | 个人战、切磋、秘技 |
| 兵法 | 智谋 | 指挥资源、阵法、军阵小游戏 |
| 辩说 | 智谋 | 礼议与交涉论据 |
| 交涉 | 魅力 | 请求、议价与委托条件 |
| 礼学 | 政务 | 举荐、正式拜访、礼议 |
| 商术 | 政务 | 价格理解、商铺经营、订单 |
| 运输 | 智谋 | 行旅速度、容量组织、货损控制 |

每半日定向修业基础20经验。先计算`normal_xp=floor(base×condition_bp/10000)`，再计算`xp=floor(normal_xp×performance_bp/10000)`；condition_bp为6000—10000，取疲劳效率和伤势效率的较小值，伤势0/1/2/3对应10000/9000/7500/6000；performance_bp正常10000、手动优秀最多12000。先取正常结果再乘加成，确保整数取整之后手动收益仍不超过正常的120%。实践奖励由模板给10—40经验，按任务实际贡献分配到最多两项技能，不能十项都涨。未来接入§3.14的禀赋及§3.15的教育条件时，先形成包含这些条件的正常学习结果，再应用手动表现修正；不得乘算多个同类天赋突破汇总上限，也不改变手动相对同人物正常结果最多120%的边界。此扩展尚不是当前公式已实现的行为。

普通定向课程费用每半日`20+10×目标技能级`钱，目标级为下一技能等级，课程2—6半日；试炼费按任务另列，不重复收课程费。师承要求教师技能严格高于学员，双方在同一据点且可用；普通技能至2级可在公共设施学习，3—4级需要合格教师或明确实践考核。P1每项技能必须至少有一条不依赖唯一会死亡NPC的成长途径：设施至2级，加两名候选教师或技能实践考核至4级。自动小游戏不阻断这些途径。

运输等级每级提高行旅进度2%，最多8%；随身基础运力20，运输每级+2；车队另加80而非乘算所有货物。提升运力改变组织效率，是游戏抽象。

## 3.3 体力、疲劳与伤病

体力0—100，疲劳0—100，伤势等级0—3；疾病为具名状态，含严重度与剩余疗程，不输出现实诊断或药方。体力=0通常表示失去继续个人战能力，不自动死亡。

疲劳0—39效率100%，40—69为90%，70—89为75%，90—100为60%。战斗数值在开战快照读取修正；不因播放速度改变疲劳。旅行每半日疲劳+5，短工+8，修业+6；休息体力+35、疲劳−30。普通休息费用20，野外休息免费但恢复分别+15/−15且处于路段风险规则内，不可重复抽遇险。

轻伤需要累计4个恢复半日，中伤8、重伤12；合格医馆治疗每半日完成2个恢复点，安全住宿每半日1点。重伤禁止主动发起切磋和重体力训练，但保留阅读、轻工、求助和治疗。伤势影响实际体力上限为90/75/50，不永久扣基础属性。

没钱且严重受伤时，乡里救助行动耗2半日、免费用、给予4恢复点，14日内同人一次；其后轻工能恢复路费。救助不会复制可交易药品。玩家不会因缺钱无法做工、又因无法做工永远不能恢复。

旧P1默认不以自然疾病随机杀死玩家；完整寿命与合法继任见07。是否启用寿终及风险须明确，不将旧“不跨世代”排除重新引入当前目标；普通失败也不隐含死亡软锁。

## 3.4 关系结构与单向性

`RelationEdge(from,to)`保存亲近0—100、信任0—100、事实标签、最后互动tick、礼物类别计数、已兑现承诺。A信任B与B信任A不必相等；同一共同事件可以明确修改两个方向，不能默认为自动对称。

事实：同僚、师徒、恩义、仇怨、结义、婚姻。师徒和婚姻等互相引用的事实通过一次原子操作建立；被俘不自动删除关系，转仕不把私人好感清零。公开声望0—1000与恶名0—1000分开。宗族、房支、生物亲缘、收养与监护保存有来源的关系事实，不能由私人好感推导；家声与传播范围按§3.16办理，不将本节个人声望自动抄给全族。

| 行为 | 初始结果 | 防机械刷取 |
|---|---|---|
| 有内容的会面 | 亲近+2；首次共同话题额外+2 | 同一对象同日只计一次基础会面收益 |
| 兑现普通承诺 | 信任+4、亲近+1 | 依任务/承诺实例一次结算 |
| 重要共患难 | 信任+8、亲近+6 | 依事件实例，不依打开对话次数 |
| 普通合意礼物 | 亲近+6 | 同类礼物30日内第2件50%、第3件25%、之后0 |
| 珍贵且合意礼物 | 亲近+10 | 信任最多+1，同样递减；不越过职责硬条件 |
| 有因延期且获准 | 信任0或−1 | 与无故失约区别 |
| 侵占公物/恶意毁约 | 信任−15、对应组织恶名+10 | 只影响相关主体及实际传播范围 |

礼物转移先确认，价值来自真实物品；对方不收则不消耗礼物，但若已经开始实质会面仍消耗该会面时间。信任不通过普通问候增长。

### 请求判定

先检查硬条件：主体存活、能接触、本人可用、技能/身份资格、权限与不可违反的承诺。硬条件失败不抽随机。可协商请求再计算：

`score = floor(亲近×20/100)+floor(信任×35/100)+floor(辅助属性×15/100)+5×相关技能+利益修正(−20…20)−请求难度(0…60)`。

score≥40直接接受，≤10拒绝；中间允许一次礼议协商，最终成绩转换为−5…+5分后再与门槛30比较。P1不再额外掷随机骰决定对方突然反悔。这样拒绝原因可以解释，关系和能力真实有效。相同处境被拒后重新打开不改变判断；硬条件或关系发生实质变化才重新评估。

举荐采用礼学/魅力，授艺采用对应技能与信任，借用物资采用交涉及信任。借用只能授予借出者有权支配的资源。友好不能覆盖敌对军事禁令；一次议价优胜不能替无权者签订势力同盟。

## 3.5 卡片数据与跨局语义

本项目分类为人物、技艺、武功／秘技、心法、战法、称号和见闻。各类在学习、战斗、经营、探索及身份变化中承担不同作用；不是随机抽牌才能行动的牌组战斗。

`CardDef`字段：id、category、name_key、description_key、prerequisites、acquire_condition、effect_kind、effect_params、hint_key、icon_id、repeat_policy。效果从已定义并已接入规则的类型选择：解锁人物、解锁行动、修正能力参数、提供武功／心法／战法、称号资格、记录见闻。具体效果与适用条件必须由所属规则实现，未知效果报错，文本不能执行脚本。

局内`learned_card_ids`只说明已经学会哪些本领，武功与心法还须记录各自的掌握程度、修炼进度及当前配置；实际能力由这些状态与使用条件共同决定。持有秘籍的物品状态、人物所学本领、全局`discovered_card_ids`发现记录与`unlocked_actor_ids`人物解锁分别保存，不能相互冒充。

人物卡只提供相应新局开局的选择资格，仍须满足所选剧本的开局条件；本局招募依本人意愿、可接触性、任职与承诺另行判断。获得人物卡不改变该NPC的所属、关系、位置或职权，不提供任意切换当前控制人物的按钮；合法继任使用07及本章§3.18的同世界程序。原12张人物卡是区域样本，不限制完整剧本符合条件的具名人物覆盖。

新周目不复制钱财、装备或本领；同一世界的继任按知识传授、典籍与学习规则承接，不复制前代全部修为。重复发现不重复叠加被动效果或奖励；有意义的继续修炼正常记录成长。原设计的单个卡片ID列表不足以承载完整功法体系，实施时需连同保存校验一起补齐。

## 3.9 从求学到自成传承的持续循环

人物成长不是每隔固定时间点击加点。基本循环为：听闻人物或本领 → 在城镇、山门、宅邸、军营或旅途中找到来源 → 建立资格与承诺 → 学习/研习 → 有代价的修炼 → 生活或实战应用 → 反馈、关系与新的机会 → 授徒/传承。教师、学生、同门和对手是世界中的同一人物，课程占用、出征、失约、受伤和死亡会改变下一步，但基础成长有替代来源。

| 层面 | 必须区分的状态 | 实际反馈 |

| 已知线索 | 听闻名称/教师/典籍及消息时间，不等于已经获得 | 去哪里、找谁、还缺哪类资格，未知内容不全知揭露 |

| 修炼与配置 | 武功、架势、心法的配合及代价；外在装备仍单列 | 能力或可用行动的变化，切磋/工作中可验证的效果 |

## 3.13 宗族、家庭与房支：贯穿各类人生的长期关系

宗族、子嗣与声望是完整人生的重要部分。玩法以人物为中心：谋生交游→成家或建立非血缘承接关系→经营家庭/共同事业→抚养、教育与授徒→成年成员各自任事→留族合作、迁居立房或协商分产→前代退隐/死亡后的多项承接。可借鉴CK3式家族关系与概率禀赋培养的乐趣，但不复制其整套制度，也不把太阁式人物生活改成只能操作王朝总览。

家庭是实际共同生活、照护和承担日常费用的单位；宗族是有成员、房支、亲属或加入依据、共同事业及约定的长期社会网络。房支记录从何而来、谁属于该支、由谁办理哪些事务。同姓不自动同族，迁居不自动断亲，分房不必敌对。个人、家庭与房支各自可有财物和承诺，不能由“同族”推导全员共用钱包。生物亲缘、收养、监护、婚姻、结义、师承及自愿加入分别记录，未知关系保持未知。

## 3.14 先天禀赋的概率遗传、有限强化与后天技艺

必须保留血脉培养的实际乐趣：后代可能继承亲代禀赋，同类禀赋组合能够提高保留或强化的机会，偶尔出现比亲代高一档的后代。与此同时，将**先天禀赋、后天性格/成长、已学技能/修为**分为三类状态；教育不能代替遗传机制，遗传也不能代替学习。

首轮候选以悟性、筋骨、协调等少量禀赋族表达不同潜力，每族只保留一个当前档位；候选为0（无该禀赋）、1—3档，3为上限。同类高档替换低档，不兼得两档效果；有限的禀赋族和档位使多代培养有目标而不无限膨胀。实际名称、族数、互斥关系、概率与效果均属平衡候选，须在内容表和作者校验中完整列出，不由文案临时追加“所有能力加倍”。出生不复制父母五属性的总和，也不因代数增加获得额外永久属性预算。

以下是一组可验证的**首轮概率候选**，只表达本作抽象规则，不是现实遗传模型；按一个禀赋族分别结算，`m`为已记录生物亲代的该族最高档位：

| 已知亲代状态 | 子代结果的候选概率 | 培养含义 |
|---|---|---|
| 双方该族均为0 | 0档95%，1档5% | 无亲代禀赋也可能自然出现 |
| 仅一方具有该族 | 0档55%，m档40%，m+1档5% | 有保留与小概率强化机会，仍会不传下 |
| 双方都有该族但档位不同 | 0档35%，m档55%，m+1档10% | 同类组合改善保留和强化机会 |
| 双方都有该族且档位相同 | 0档20%，m档65%，m+1档15% | 同档组合更稳定，但仍非保证 |

`m=3`时，m+1结果合并到3档，不产生第四档，也不改为额外属性点；每行概率总和为100%。该表仅为可复验的设计候选，本轮不写入运行配置或据此重算已有角色。亲缘或亲代禀赋未记录时，不反推“该亲代为0档”；已知一方可提供单亲加权，未知方不提供加权，若双方资料均无可用依据则使用无亲代加权的基础生成分布，结果明确标记来源未全知。收养、继任与拜师不会改写生物亲缘或重抽禀赋。外貌遗传另按§3.25的独立表现规则办理，不借本节禀赋档位决定美丑、脸型或衣饰，也不把相似外貌当成已证实亲缘。

禀赋提供实际但有界的差异，例如悟性作用于相应研习，协调作用于相应技巧学习，筋骨作用于已定义的体能成长条件；每项效果须声明作用对象和代价，不做通用于所有职业的总战力倍率。首轮学习效率候选为对应1/2/3档增加5%/10%/15%，同次学习的全部先天加成汇总不超过15%，再按§3.2结算正常成长与手动表现；具体体能类效果须另列并遵守§3.1、§3.3边界，不能借“潜力”直接发满属性。先天潜力的兑现仍需要成长时间、真实学习与可用环境。

农耕/农政、锻造、医术、商术、兵法，以及武功、心法、炼丹或符箓的实际掌握均为后天本领，不是可遗传的熟练度。匠师家中可有工具、典籍、订单和合格教师，孩子因此拥有较好的学习条件，但出生不会拥有锻造4；已有配方和家传秘籍各有物品/知识来源，不能由族谱页面一键学会。后天性格、兴趣与经历另行变化，也不全部从父母复制。

出生按唯一来源一次生成并保存禀赋及来源快照，预览只能说明已知机会，不抽取结果；命名、开关族谱、读回同一状态或重复提交不重抽。后来的修炼或其他能力变化不回写已发生的出生结果。既有人物和旧档不会追溯获得新抽样，细则见08§8.15。无高档禀赋者仍有正常学艺、做工、任职和成就路径；禀赋不成为所有职业共同的血缘门槛，伤病或残障也不作为整个人物价值的判定。

## 3.15 养育、教育与弟子成长

首轮年龄阶段候选为0—5岁照护、6—11岁兴趣与启蒙、12—17岁安全见习和师承选择、18岁起成年自主及接续资格。这是游戏阶段，不冒称汉末统一年龄制度。人物年龄仍从02的同一世界日期和出生日期计算，18岁门槛与现有合法成年接续相衔接；新增儿童成长不等于已经允许未成年主角执行完整成人行动。

每个被照护者有实际监护/照护人、居处、可用生活供给和教育安排。教育计划明确重点、教师或代教、场所、教材/工具、课程节奏、费用承担者、实际进度与中断原因。家学、学舍、作坊、医馆、山门等提供不同来源；收养子女和弟子同样有自己的已有能力、兴趣与学习史。已存在的成年人加入家庭或师门时保留真实人物，不生成同名替身。

教育状态为“拟定计划→取得本人适龄意愿及教师/监护安排→排课→进行→暂停/更换→阶段考核或完成”。一次计划只规定有限学习重点，按实际上课和实践提高相关技能，不每季自动给所有技艺发经验；教师能力、真实出勤、照护、设施、疲劳与学生兴趣形成反馈。未成年阶段仅提供适龄内容，不把儿童作为可任意征兵、安排成人危险工作或批量生产资源的对象。性格和兴趣由多次实际经历逐步形成，不用一次随机弹窗永久锁死职业。

可按月/季委托照护和教育以减少重复点击，但教师、学生和资源仍按现有行动/占用规则结算。授课者不能同时远征又在家授课；学员不能同一半日同时上课、出游和工作。成长、天气/时令内容、生产、战争及人物寿命共用同一时钟，不对孩子单独跳过十几年。长期休整/委托推进可以加速表现，遇到教师失效、供给不足、重大承诺或必须决策的事件时交还选择，不能跳过已经发生的世界后果。

贫困可选择公共启蒙、低成本实践或延后进修；失去教师可换师、使用已取得典籍或参加替代考核。暂停保留已完成的真实学习，未上课程不发经验，费用按实际提供部分结算。孩子成长方向与家长期待不一致时，可调整计划、继续沟通或接受其独立生活；成年后仍能转业和学习。教育改善发展、发挥先天优势，也能帮助普通禀赋人物形成完整事业，不能被设计成筛掉一批无法继续游玩的后代。

## 3.16 成年婚姻、婚盟与家声

婚姻由成年双方的真实意愿和有效身份条件成立；家主、亲属或媒介可以引荐、协商，不能代替当事人同意。状态为“提议草案→送达→协商→双方同意具体条款→办理生效→履约/变更/解除/丧偶”。提议不直接生成配偶、扣赠与或强制结盟；生效前撤回与生效后解除有各自清算，重复打开被拒提议不重新掷骰改变意愿。礼议、魅力与家声可以影响合资格请求，不越过不同意的硬条件。

婚盟可以连接家庭或房支利益，其条款须列出当事人、有权承诺的代表、居处与往来、财物赠与/费用、支持事项、期限、照护和教育如何协商、变更或解除后的未结责任。赠与来自真实可支配库存，婚后原有财产仍按权属，不能把配偶处理成增加属性的装备或免费的整个家产包。双方仍有独立职业、交友、行动、物品与承诺；婚姻不保证生育，也不作为继续世界的唯一前提。生育安排保留成年当事人意愿和真实照护条件，不靠连续无成本按钮立即生成一批成年人。

婚盟可形成引荐、共同经营、访问、具体救助与供给约定，履约或失约影响相关关系和家声。只有政治组织的有效授权者能另行订立政治/军事条约；姻亲不会自动得到官军、公库、任官权、另一方领地或宣战权。私人支持与公职职责冲突时必须显示权源和后果，仍执行04及06的政治契约。

家声与个人声望/恶名、私人亲近/信任分开。家声来自有来源的共同事业、守约、救济、讲学、名作、从政表现及争议；记录涉及宗族/房支、事迹、相关人物、知情圈层和传达时间，按乡里、师门、商旅或政治圈的实际认识发挥作用。家声可改善初次接触和引荐机会、提供有限信用，也带来旁人期待，但不复制前代私人信任和功勋。一个远方成员的行为不会立即让全世界全族同涨同跌，旁观者按所知事实、责任及立场评价。

继任者保留别人已知的家族背景，同时能以自己守约、任事、作品、交往和处理旧承诺建立或修复声望。分房不抹去共同经历，也不把原家声无条件复制为两份可叠加增益；族内合作、独立立业与疏离都应有可读原因。家声、引荐与门第因素不能使无家族背景的人永远无法学习、谋生或出仕。

## 3.17 族产、各户私产与分房分产

| 财产情境 | 权属与办理依据 | 交接边界 |
|---|---|---|
| 个人/各户私产 | 明确所有者或共同持有者的产业、物品、钱粮与债务 | 可以依法定游戏程序赠与、出售、共同经营或承接，不能支配他户财物 |
| 宗族共同财产 | 共同持有依据、用途约定、成员权利、收益安排与受托管理 | 族内主持人只是按授权管理，死亡不将全部族产变成其子女私产 |
| 政府/政治组织公产 | 组织所有、岗位授权、预算与公共用途 | 任免、政权更替依政治交接办理，不随婚姻或私人分产转走 |

所有权、收益权、管理权、居住/使用与指挥授权分别说明。与07§7.12的庄园、坞堡、部曲和宾客相连接，但庄园居民、门人、宾客及部曲是实际人物和关系，不是可以按继承份额分割的人身资产。离庄、投效、供养、借调和返还按承诺与意愿办理；同一批人和粮不能同时计入两房经营、庄园生产和军队。

分房是成立独立生活或经营单位，分产是改变具体财产的权利，两者可以分别发生。状态为“提出→清点资产与责任→协商方案→必要同意→提交重验→一次转移/登记→履行后续”。方案必须列明来源、具体物件/库存批次或产权份额、接收方、预留与债务、照护责任、经营安排、费用及剩余共同部分。多个候选方案不重复预留同一资产，旧预览遇到资产变化必须失效。

可分物资按整数数量转移，余数在确认方案中明列；不可分建筑/产业可留为共有并约定管理与收益，或由一方取得并以真实资产补偿。不得把一处庄园拆成两份完整设施和产量，也不能用不存在的现金自动补齐公平。债务、预留、在途货物与外借物资不随分房消失；不能达成方案时保留原权属，可继续协商、先迁居、延期处理争议部分或选择合法出售，不因争议冻结人物全部人生。

分房后仍可共同祭会、教育、经商或供养防务，也可疏离；不自动生成政治独立、宣战或全族敌对。族产被侵占须有具体行为、受影响权利与消息后果，不靠直接改管理者就合法洗成私产。

## 3.18 亲生、收养、旁支与弟子的多路径接续

接续同一世界的候选人必须已经存在、达到成年门槛、自愿、具备可查的承接依据和合法可玩处境。候选包括成年亲生或收养子女、有真实关系及认可的旁支、经有效成年收养程序加入者，以及经指定并满足相应传承程序的弟子/门生。不得把“无亲生子女”直接判为无法继续；收养和门人承继是完整道路，不是数值较差的临时补丁。

成年收养保存原人物、出生日期、已有本领和原亲缘，再增加新的社会/家庭事实；不补抽禀赋、不改成亲生。弟子可接受事业、典籍、合法赠与及传授责任而不成为血亲，也不要求先强行收养才能接续。拜师并不自动接受继任，指定须本人接受，并依涉及的产业/组织程序取得必要认可；政治继位仍按04§4.13和07§7.15另行核验。

接续方案逐项展示：

1. 玩家将继续操控谁，以及其自己的年龄、技能、伤病、地点、行动与承诺
2. 哪些个人/家庭资产实际移交，哪些族产只变更管理或保留共有，哪些义务需要清算
3. 典籍、教师、配方线索和传承许可如何延续；本人实际掌握仍是已有学习成果
4. 哪些私人关系、家声和旧承诺按知情事实继续，哪些人需要重新建立信任
5. 官职、门派职位、族内主持资格和政治首领资格各自保留、重任、代理或有争议的原因

主动退隐经本人确认、候选接受、交接预览与稳定边界提交，前代存活时留在世界，不抹去其经历。改变玩家与改变政治首领是两件事；可以家产移交成功但政治继位失败，继任者继续为臣、经商或学艺。前代完成的统一/职业成果保留为历史，不让后代重复领取物质奖励，也不保证所有旧部继续服从。

死亡属于非自愿中断，不能要求死者空闲、回到家中、等部曲全部归庄或亲自清空工程后才允许世界继续。产生遗留事务、明确权责的成年代管人与待定权利；施工、债务、在途货物、外出部曲及公共职责分别继续、暂停或清算。未成年成员可保留其资产权益与照护安排，暂不因此成为可操控成人或统军者；代理权限有来源、范围与终止条件，不自动取得遗产所有权。具体事务与保存见08§8.14。

没有合格候选时明确提示缺少什么，可保留终局存档；生前可建立的成年收养、旁支或弟子接续途径必须有可达内容。死亡时不能凭空生成满技能继承人，也不让已具备合法接续关系的成年人仅因未使用旧收养命令而被永久排除。家族争议、政治失败或失去一项产业不自动删除其余合法人生。

## 3.19 家事事件、失败出口与场景呈现

| 事务 | 生效和推进边界 | 失败/中断与继续 |
|---|---|---|
| 婚议/婚盟 | 送达、同意、办理、赠与及支持履行分别有来源和状态 | 拒绝不生成婚姻；缺席可延期；撤回/解除清算实际已提供部分和未结承诺 |
| 出生与照护 | 有效出生事务到期生成唯一真人、一次禀赋结果和亲缘/照护事实 | 照护者失效转入有依据的代管/求助；未命名用稳定暂名，不因命名画面未打开而重复出生或卡住世界 |
| 教育/授徒 | 计划、排课、实际课程、成长、考核分别记录 | 教师缺席不授课，换师/转业不抹掉已学；学习费用与占用不重复结算 |
| 分房/分产 | 明确成员去向、资产方案、同意及一次转移 | 争议保留原权属；延期处理有期限的义务，资金或承载不足不得生成补偿物资 |
| 退隐/死亡接续 | 先核验接续和各项权利，再在稳定边界改变控制人物 | 主动移交可先排除阻碍；死亡走遗留事务及有限代理，不套用死者亲临前置条件 |

所有事务使用02的同一时钟、接触与行动占用；预览只读，提交重验，进行中已有实际成本保留，终态不可重新启动。NPC家庭与玩家家庭使用同一规则，重大选择排队进入稳定边界，不在半日结算中递归打开弹窗。生育/出生内容须有成人意愿依据、起止时间、照护和失效规则，不能只用一个出生关系标签冒充完整循环；本轮不制定现实生理公式。

UI-31以具体家人、房支和师承人物为入口，展示已知关系、阶段、本人意愿、教育安排、家声事迹、分产与接续预览。婚议从实际人物/已送达文书发起，教育在学舍、宅邸、作坊或山门中有教师与学员，分产由有权当事人或代表办理；家谱只读展示不能直接发人、发钱或学技能。产业、门派、公职与政治事务分别链接UI-27、UI-29、UI-34/35，不再造一套全资产通吃的家族总控。画面沿用09的统一表现规则，未成年人形象和文案与其阶段一致。

## 3.21 共同经历与承诺：从已经发生的事改变下一次选择

**2026-10-01体验吸收与底层补充：本节至§3.24是待实现的领域合同，依据241a0da源码作只读核对，未运行新测试。** 目标是让共同患难、守约、失约和有因延期改变人物的实际选择、能透露的消息与再访对白；不以多存几行日志或统一增加好感宣称完成。保留§3.4单向关系、§3.16局部家声和06§6.12非全知社会，不引入运行时大模型或另一套人物世界。

世界中已发生什么、某人曾答应什么、另一人听说了什么、他如何理解这件事，必须能分别回答。采用在已有领域事实之上的有来源关系与认知投影；不采用“全局日志就是人人记忆”，也不为每段对白复制任务结果。

| 合同记录 | 权威归属与最低语义 | 不能承担的责任 |
|---|---|---|
| `ExperienceRef` | 引用已经提交的任务、战斗、学习、交易、援助、委任等领域事实及其版本；包括真实参与者/承担角色、地点、发生时间、结果与可观察部分 | 不另外发奖，不把同城所有人都标为共同参与者，不将未发生的计划写成经历 |
| `CommitmentRef` | 引用Task、Mandate、教学约定、外交等所属领域保存的具体承诺；可查询许诺者、受益/相对方、内容、期限、接受依据、可替代性、当前状态和履约证据 | 不另存一份可独立改变的任务成功、期限或清算状态；关系系统不裁定工程/运输是否完成 |
| `KnowledgeClaim` | 某人实际接收到的一份消息内容快照、原事时间、获知时间、渠道、直接来源与前序传播引用；标明亲历/正式回报/转述/待核实及所知范围 | 不向接收人自动展开真实世界全部字段；转述者说“已交粮”不等于实际交付 |
| `MemoryEntry` | 个人对已知经历/承诺的有限评价、相关对象、评价依据与规则版本、首次获知与最近订正、显著性及后续回应记录 | 不改历史真相，不因再次打开人物页重新抽取评价，不把所有人压成同一个善恶值 |

记录名为设计接口名，尚非当前Schema。终态事实只保留所属域的一份权威结果；需要关联多领域时引用这些结果ID，不能另外生成一份同名世界事件替代原结果。`KnowledgeClaim`允许不完整或错误，世界真相仍由原领域决定；没有来源的传言不能凭空入库。发布者的断言、接收者的相信与玩家能验证的证据分别表达。

私人承诺绑定当事人；公共委托绑定发令组织/合法岗位及合同连续性。管事接替公事可看有权接触的工作记录，不继承前任与玩家共患难的私人记忆。未答应的邀请、拒绝不合理请求、已获同意的延期、不可抗力中断和恶意失约必须区分，不统一扣信任。仅声明“我会帮忙”不能创建资源、权限或任务收益；确立有约束承诺须经过对应领域的明确接受入口。

### 对行为与对白的真实作用

1. 领域合法性先检查身份、地点、占用、授权、既有承诺和实际资源，私人信任不能覆盖这些硬限制
2. 计划选择读取本人已知的共同经历、尚待履行的承诺和有界评价；可以影响是否愿意同行冒险、替人担保、接受赊借、提供消息、继续合作或要求先办完旧事。至少一种后续合法行为必须不同，不能只换问候句
3. 对同一已知事实，不同人物可以按既定利益、立场与性格产生不同的有界解释；喜欢、信任及当前立场分别供查询，立场引用实际利益/组织/承诺，不把私人喜欢当成政治同意
4. 白话反馈引用相同证据和决定理由，例如“上回你护住了车队，我愿同行”或“旧约尚未了结，先办这件事”；对白只选择已校验模板和已知绑定对象，不自行生成事实、承诺或资源
5. 获知订正可改变当前判断；曾经误信导致的旅费、失约和选择仍是已发生事实，不因查明真相回滚世界

普通商店和基本生计仍按11开放，不把每次买粮变成关系门槛。亲近带来的生活反馈可以是愿意多谈一事、记得共同经历或主动相邀，不要求每段友情最终都兑现为军事/经济收益。

## 3.22 社会认知的命令、查询与事务边界

这些能力归入现有社会/关系领域的扩展，并由架构注册表声明内容能力与依赖；不建全能`MemorySystem`去重写其他领域。Task/经营/战斗等模块产生并验证自己的事实；社会领域拥有个人知情与评价；计划模块消费查询产生候选命令；Interaction/Dialogue负责合法接触与表达；表现只读取带观察者的投影。

| 设计接口 | 输入与输出要点 | 纯读或提交约束 |
|---|---|---|
| `known_experiences(observer, subject, context)` | 返回观察者确实知道、与现场主题相关的经历引用、关系角色、消息来源/时间、已知结果和可信边界 | 纯查询、隔离副本；未知内容不以空值字段、数量或排序泄漏 |
| `commitment_constraints(actor, proposed_action)` | 返回本人的未结承诺、会冲突的职责/时窗、可延期或需同意的条件以及所属领域引用 | 供正式领域校验及计划筛选共用；内部校验可读完整合法性，面向玩家的解释必须另作知情过滤 |
| `social_response_preview(actor, counterpart, request, context)` | 硬限制、愿意/拒绝/可协商、所依据的已知经历及可展示理由；评价修正须有来源和有界规则 | 不改关系、不消费随机、不占用人；不能把此预览当成领域动作已经成功 |
| `explain_known_result(observer, result_ref)` | 将本人行动回执或已送达报告整理为“已知原因→实际影响→仍不确定→下一合法办法”，保留事实/消息引用与时间 | 查询不能越过已知范围查询敌方计划；内部调试因果与玩家可见说明分开 |
| `request_social_action` / `share_known_claim` | 指明现场相对方、事项/消息引用、传播渠道和已知revision；请求实际借物、担保、帮助或交谈 | 由Interaction复核在场与服务，再调用所属领域命令；分享只传播已获知且允许透露的内容 |
| 领域完成/订正接入 | 提供同次候选中的领域结果摘要或既有已提交结果、直接参与者、可观察内容及订正依据 | 在同一候选事务中登记事实引用、初次亲历、必要关系/评价和唯一结算，整体成功后共同提交；不能等UI通知被消费才产生记忆 |

对白条件通过注册的`has_known_experience`、`known_commitment_state`、`social_response`等受限语义查询，而非任意`get_field`、全局flags或自由脚本。作者需指定观察者、对方、事件类别/角色和适用时间范围；编译时核查字段、参与者绑定、可用能力和文本变量，运行时复验消息是否已送达。对白节点隐藏与真正命令合法性分别检查。

一次任务交接候选事务包含实物/钱款转移、任务终态、履约事实及直接当事人的初次认知；任一关键校验失败则整体丢弃。远方相关人的认知不在此时更新，而是另行通过有渠道的消息送达命令提交。借物、担保或援助在接受时建立相应领域权利与承诺，在实际交付时转移物品；“愿意帮”不等于一键得物。重复请求、对白回看和报告重开按同一结算/认知键幂等，不能再加一次信任。

现有社会规则每半日只传播步初已知的一条消息，这个行为在首轮兼容迁移中保留；若更改传播频率或渠道必须单独标记规则版本。传播链指向更早的合法获知记录，并有实际接触/送达证明；不能通过同一半日循环转述变成全城知情。本人何时听说与原事何时发生都要保存，事实已过期也不得偷偷把旧消息刷新为现在。

## 3.23 生命周期、长期保存与现有底座缺口

### 生效与保存

- 亲历来自真实完成结果；转述来自有效送达。提议、拒绝、接受、生效、履行、延期、解除、违约各自引用相应领域边界，不由通用记忆模块用一个计时器替所有领域判约
- 活跃承诺、长期恩义/仇怨、师承、继任依据及当前知情来源不依赖短命令历史。普通回顾可以合并显示，保存压缩仍保留被引用的稳定事实、参与者、发生/获知时间、传播依据和结算键；本轮不要求全世界事件溯源重放
- 记忆显著性可按固定游戏tick和已声明规则衰减，法律/合同义务不随“淡忘”消失。订正追加来源并标明当前判断，不能删除原先听说及据此行动的历史

## 3.25 人物外貌、年龄与分层形象的稳定合同

**2026-10-01用户已批准表现成本与架构路线；以下是待实现的设计合同。** 关键人物采用专绘，普通人物采用受约束组合，统一为分层2D。日常资料、名单、会面和成长以头像/半身为主；少量特殊名人或叙事场景可有专绘全身/情境图，不要求所有人物制作全身、全部年龄逐件装备或独立动作全集。专绘与组合共享同一人物身份、年龄和状态来源，不能各自维护一套人。

| 来源 | 外貌确定方式 | 稳定性与限制 |
|---|---|---|

“实际外貌特征”指此人物已经确定的脸部特征、基础体型、发须/颜色等稳定描述及必要选择，不等于一张当前渲染图片，也不只是一组可以随资源排序变化的数组下标。具体字段、部件数量和生成权重在实施时版本化；本轮不假称已有同名Schema。日常衣饰/姿态、年龄阶段、伤病及战斗状态是相应事实的表现输入，不从画面反推新的属性或权力。

### 年龄变化与儿童比例

人物年龄由同一世界日期和已存出生日期计算。面部成熟/老化、发须和体型使用对应阶段的已制作变体，保留可辨认的个人基础特征；年龄推进不重新抽基础脸型或生成另一套身份。儿童的头身、肩宽、四肢和半身裁切采用独立比例及相容衣饰，不能拿成人图统一缩小冒充儿童。婴幼儿、儿童、少年及成年阶段以实际支持的内容和§3.15规则对应，未完成的阶段明确标缺口，不能由画面外貌自动开放成人行动。

专绘人物同样需要可解释的阶段适配，不以一张成年名人立绘覆盖童年。具体阶段分界、变体数量和过渡手法属于制作细化项；先用代表人物证明连续性和成本，再扩充。衰老是按日期与已声明规则改变表现，资源更新不能代替人物老化，也不能把新素材当成允许重抽的理由。

### 外貌遗传与先天禀赋分开

亲生子代的部分基础外貌可按已记录生物亲代的特征，使用受约束的独立组合/变异规则生成，保留相似性但不要求逐项复制。其结果与§3.14的先天禀赋抽样分别有规则版本、来源和输出；外貌不产生额外技能或能力预算，禀赋档位不决定外貌结果，也不把漂亮/相似程度作为能力高低。两者可以在同一次合法出生事务提交，不能共用一个含义混杂的“基因值”。

亲代外貌或亲缘未知时使用已声明的无该亲代加权分支，结果标明可用依据，不能为补外貌而制造父母。收养、监护、婚姻、拜师和继任只改变其实际关系或职责，不改生物亲缘，不向被收养者重套养父母外貌，也不重抽既有外貌或禀赋。亲代后来换发式、衣饰或年龄阶段不会回写已出生子代的生成结果；生成时的有效基础特征依据保留可追溯来源。

### 衣饰分层与有限战斗形象

日常形象将脸部、发须、身体、衣饰、配件及前后遮挡按已校验模板组合。服装必须声明适用体型、年龄比例、姿势和遮挡关系；不把一件成人正面衣服强行缩放到儿童或任意侧身。组合不兼容时应在作者校验/创建选择中明确拒绝或禁用，并说明缺少何种变体，不能在运行时拉伸、穿模或随机换身体凑合。服装所表达的身份和当前状态读取真实任职/处境，穿上对应图层本身不授予官位或战斗能力。

战斗采用有限的简化人物模板与已支持的可复用特征，如体型、发色/发须轮廓及配色；可共享基础模型/图层和动作，不要求每位NPC或每件装备都有一套战斗资源。稳定头像、姓名、阵营/队伍和选中反馈必须共同保证人物身份。刀剑、长兵、弓等动作类别服务规则可读性，但不承诺逐件显示当前真实装备换装；实际装备的属性、可用招式、距离、消耗及效果仍由同一规则计算并可在详情/结果中核查。装备外观省略不能成为漏算效果或同人换身份的理由。

本节不降低总纲19.4及09对移动、出手、命中/落空、格挡、受击和退离的可见反馈要求；也不把纯静态立绘滑动称为最终动作完成。世界地图、城市总览、房屋内景与战斗通过同一人物/地点ID取得适合尺度的投影，返回日常后仍是同一人、同一地点和已经发生的状态。

## 3.26 外貌、年龄与身份连续性的验收范围

原T11—T20、CLAN01—12、SOC01—08及VIS/IMM全部保留，下列是与09和08§8.19联合执行的新增情境要求，不是通过记录：

- 史实固定人物、普通生成NPC和自建人物分别从合法入口出现；同一人物重复访问、预览、保存重启、在相容资源版本间恢复后，实际外貌特征、生成版本和seed不变
- 同一生成/出生来源重放不重抽、不新增第二人；仅打开自建/族谱/人物页不改变玩法随机或世界状态，取消预览不消耗资源
- 同一人物从儿童成长为成人再进入老年，面部、发须、体型与实际年龄对应；儿童独立比例和衣饰有效，阶段切换保留可辨识身份，不借成长重置关系或能力
- 亲生后代分别测试双亲、一亲已知和未知外貌来源；外貌组合与禀赋结果各有独立依据，收养/拜师/继任不改血缘、不换人、不重抽，父母高技能不会变成遗传熟练度
- 多体型、多姿势、儿童衣饰和缺失/不兼容部件分别验证；非法组合在作者/选择入口可定位，兼容资源替换不改变已保存特征，无法兼容时明确报告
- 同一战斗中共享基础简化形象的不同人物仍可借头像、姓名、阵营和特征辨认；更换真实装备后无逐件外观变化仍能验证其合法规则效果，回日常不换脸、不丢状态
- 世界地图、城市、内景与战斗/返回共同验证人物位置、年龄与现场状态来自同一世界；远方/未获知事实不因人物或背景层变化而泄漏

验证报告须分别列文档合同检查、规则/保存测试、作者内容检查和真实引擎画面；样板尚未制作时保持未测，不用固定seed、同一姓名或概念图替代实际身份连续性证据。
