# 青川安民：原署委任与本人受领

本包依原青川 1.11 人物、道路、钱粮和政治治理规则，显式选择 `political_governance_intents/1`。县仓书佐沿原 `office.city_steward` 及 `grant.qingchuan_appointment` 委任程叔；程叔在本章初态明确为城署成员，没有初始任务或执行承诺。

玩家从原见习人开始。推进原世界时钟后，两位 NPC 各自沿原 Director 公平预算、原治所及真实当前权源办理。签发使用原 `political_commission_governance`；受领使用本人原 `governance_accept`。原双方不在场、已有行动或职责、钱粮不足、失去职权、成员拒绝新责任时继续由原规则阻止。

一次意图只消费首次真实邀请。受领后仍执行原六半日安民工作、120 钱与 10 粮的原家庭分配；没有预先写入邀请、任务、批准、支付、民心或完成事实。已过期邀请不会由此意图自动续签。

作者结构和来源检查与实际世界运行分别记录；本包目前尚未作完整 World 行为验收。
