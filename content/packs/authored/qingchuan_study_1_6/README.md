# 青川习业 1.6.0：课程逐半日积累与原题续答

本包承接 `qingchuan.study@1.5.0`，独立目录与精确选择文件为 `content/packs/selections/qingchuan-study-1.6.0.json`。每门原普通课程显式声明 `settlement_policy: per_lesson_v1`，只有接受该作者条款的新开课采用分段结算；旧包和旧课程事实仍按原终结结算解释。不能为旧课补发历史经验。

每个实际教学半日支付原课费、增加原疲劳并取得对应经验。原礼议和筹算题可以照旧晚答；未答完的课时先给原自动基线，答完后只补这些已听课时的原表现差额，后续课时使用同一成绩。题面、三轮选项、评分、120%上限和开课一次抽种都不变。没有先听课就没有答题经验，退出练习采用原自动成绩，结束课程不重复授奖。

暂停释放原师徒，让双方可以另作安排；原行动、已听课时、未用课费、题面及已选答案保留。续课必须原教师仍在、合格且双方有空，不自动换教师。结束课程保留已获得经验，只释放尚未提供课时的预留款，原课程不能再恢复。

## 正常游玩入口

从标题页“启程”选择锁明确属于1.6.0的“青川习业：初来集上”，仍是原程禾、原120钱盘缠和零经验。去讲舍打开“本处课程”，选择礼法、三半日、“报名 · 亲自完成练习”。初学三课按原报价预留90钱，报名本身不走半日；日后盘缠不足时仍可到粮行按原条款做短工。

可以先按“继续一个实际半日”，看到本课程已获得经验；完成原第一轮选择后暂停。经系统菜单真实保存，再从新标题“继续”恢复，进入暂停课程并恢复原课，仍是同一先生和第二轮题。答完余下两轮，只为已听的一课补原表现差额，时间、课费和疲劳都不因此增加。再次暂停保存，恢复后继续或结束，都不得重复取得这笔差额。原商术筹算课程同样使用这套规则。

## 内容与验证边界

人物、所有五个剧本初态、钱包、课程、题目、选项、难度、服务费用、个人战、武学和五张原画全部继承1.5.0。仅包版本、原课程的结算政策声明及先生/商人的课程说明改变；没有测试专用人物、赠款或预置成绩。所有资源继续使用原manifest摘要。

正常组合仍用 `tools/content_pipeline.py compose --packs content/packs/authored --selection content/packs/selections/qingchuan-study-1.6.0.json --output <新输出目录>`。课程政策的Schema与注册必须先在中央集成，然后才能生成自己的目录锁与安装代。准备helper和作者输入不代表Main、物理存档、独立进程恢复或视觉验收已通过；实际证据由最终绑定源码与原生库的联合节点给出。
