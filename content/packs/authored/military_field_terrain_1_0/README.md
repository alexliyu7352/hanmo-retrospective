显式 military_field_terrain/1，field_watch::scenario.terrain_road。沿原青溪军官受职、编军、真实路段接敌进入独立 field.terrain_road，原围城道路仍保留。新场与原 approach 使用同一军令目标，不预造接敌或战果。
