# 青川与松门 1.1.0

正式后继包 `hanmo.local_society@1.1.0`，由 `content/packs/selections/local-society-1.1.0.json` 选择。保留 1.0.0 的独立源与选择文件；本代原有“初春供养”“农忙练武”情景的作者记录不改。沿用项目已授权的同 SHA 美术，缺失资源仍须按原正式 stage 流程恢复，不能用占位图代替。

## 公托归粮

新增正常标题可选情景“公托归粮 · 组织采购与山路风险”。程禾从松门门口开始，持有松门组织明确的采办职务和成员身份；实际经办人仍是松门执事。到“查看地方近况”选择“代表组织承接”，合同由松门负责，程禾实际执行。组织名不冒充人物，不另建一份任务或采购款；本次报酬进入授权的松门公账，不发到程禾私囊。

沿原地图去青川，在粮行通过原商户对白进入货单，选择本合同采购经费和四件粮食。返回松门途中，已在世界中往返的持械行路人可能与当前行程实际交会。应战沿既有个人战界面执行；获胜、退离或没有相遇都不会触发败北货物政策。

本情景对松门粮食采购模板显式声明 `fixed_caps_v1`：仅实际败北，把开战时最早有效合同的原有受托粮最多一件转入实际对手背包，再最多损毁一件。对手不具备接收资格时不处置。声明不会制造遇敌、战斗结果或货物；不取第二次随机数。四件实物若实际适用上限，仍有两件可沿原路带回，通过合同按钮交付。只有实际交付计入报酬，未用采购款依原冻结条款退回来源。

## 明确的开发参数

本代新增数字均为 provisional，不是最终平衡承诺：山路每程四半日，行路人从第六半日起往返、到达停留一半日，初有240钱作为实际行旅盘缠；松门公托单份最多四件，期限三十六半日，败北转交上限一件、损毁上限一件。采购预算仍每件20钱、报酬每件2钱。个人战使用既有武器和技能命中模型；48回合上限、败北伤势2是显式情景目标，不修改原战斗算法。

初春与农忙的既有经济、工资、训练和NPC采购继续由相同原生规则推进。公托情景仅让松门原采购者继续既有责任/等待，不与玩家争本次采办入口；县仓采购者保持原有限决策。没有隐藏补钱、凭空生成匪帮、自动扣光货物或后台再判一次输赢。

## 验证边界

作者Schema、实际引用、模板/物品一致、政策上限、profile/capability与真实行旅来源作静态准入。`game/tests/test_dynamic_obligation_player_flow.gd` 是中央联合节点可调用的实际Main操作片：真实组织接单、采购、相遇、逐回合输入、败北、余货交付和合同清算。只传正常控件命令，不注入战斗或货物事实。具体运行结论以中央同代构建回执为准。
