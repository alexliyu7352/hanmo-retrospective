# 青川往返信件

独立 `hanmo.task_message_returns 1.0.0`，namespace `returns`，场景 `returns::scenario.qingchuan_round_trip_letter`。依正规 `hanmo.local_society 1.11.0`；原私人先生与剑院执事、地点、钱包和信件责任继续沿原作者。

新选择 `task_message_returns/1`。先生明确要求收到回书才结酬，期限为受领完成后32个半日。承运人须真实受领、实交去程，随后在执事 `entrust_return` 本人SAY处通过“信件往返”页接回书；原半日办理成功才生成唯一Task产权回书。返回先生实际会面，再用原任务页报告并实转原件，原Task唯一支付。

取消仍原Task预算与实物返还。原件丢失、过期或双方不在场不会凭到城结酬；未完成回书不计完整履约。新包不预置Task、去程handoff、回书lot、实际result、死亡或同意历史。已通过固定公共候选的正规内存合包与完整作者语义门；未导出素材/Installed，完整World行为仍待验。
