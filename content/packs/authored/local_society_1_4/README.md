# 青川具名任职 1.4.0

正式后继包 `hanmo.local_society@1.4.0`，精确选择 `content/packs/selections/local-society-1.4.0.json`。沿用1.3同一工程、人物、商店、道路、Task合同和原美术。新包不会替换旧包或旧存档身份。

## 正常标题入口

- `scenario.society_membership_funded`：工资原账240钱，粮行40粟。程禾现任县务代表，向当场相识的谷诚和沈蘅提出具名邀请。谷诚的工资底线低于所提条款，沈蘅的底线较高；结果须由各自实际复评得出。
- `scenario.society_membership_short`：县务工资原账3钱，粮行2粟；程禾原有4粟，其中2粟可补旧合同余缺，另2粟面对其他人物自己的备粮需求。初期可付真实首期，后续工资自然不足；组织采购尚须4粟，所以执行者会在买到两粟、实际交付之后等待余货。其本人按已知欠薪请求离开，原任务与受托物仍归原owner。程禾原本持有的四粟最多可在粮行正常出售，再由执行者继续原采购与交付。
- `scenario.society_membership_deferred`：工资240钱、粮行1粟。沈蘅先按普通个人合同政策承接县仓真实需求，单次最多2粟。玩家等原承接及首份采购交付完成后邀请；余货不足使旧合同暂无可执行下一步，本人可以真实暂缓。玩家可出售原两粟尝试缓解缺货，原责任仍按实际预算、商品竞争和原期限办理；本条有限路线会依法部分到期清算，邀请也按原24半日期限失效，不自动改成拒绝或延长。
- `scenario.society_membership_recipient`：实际县务职务由县仓书佐持有，作者招聘职事只点名程禾一人。真实NPC职事发邀请，玩家从正常人物事项中接受、拒绝或暂缓，开局并不是组织成员。本局招揽者每2半日复评，实际1半日等候行动之间留有真实空闲接洽时窗；其他三局仍每1半日复评，旧动作占用规则不变。

compose后情景及人物实体统一带 `society::` 前缀。条款 `terms.city_contract`、个人政策和动态office/grant是本情景内部ID，不额外加前缀。关系是有来源的作者熟识关系，信任/好感初值均为0；关系数值不换成忠诚或自动同意。

## 明确条款和有限政策

所有工资/阈值是 provisional 开发参数：合同执行职责每2半日计5/2钱，整数真实支付、余数精确保留；接受后经过完整2半日才有第一期，不补过去进度。邀请24半日到期，前三局Director每1半日复评，玩家受邀局每2半日复评。谷诚底线每2半日2钱；沈蘅底线每2半日8钱。已有行动、任务、受托物等真实职责优先；没有心理评分、随机拉拢或预填同意字段。

唯一招揽授权 `grant.city` 同时包含 `organization_offer_membership`、`contract_executor`、真实当面场所、组织工资钱包和1000钱上限，允许委派；既有 `claim_need` 仍用同一真实组织Task路径。收到合同酬金的是报价所选的原组织账户，任职工资收款人是本人，双方不复制一份报酬。玩家可以在人物旁明确选择合法组织收款账户，短缺续程可选 `wallet.city_wages` 使后续合同收入用于原欠薪。

`terminal_fraction_compensation_v1` 是本章新冻结规则：仅合法结束时已有有效账期计提的正余数 `r/d`，追加一次最小币单位1钱应付，同时记录原余数与补偿差额 `(d-r)/d`。真钱从原工资钱包扣；不足即原雇主整数欠期。零余数、没有有效账期、拒绝或暂缓不生钱。重复离开、恢复和再入职不能重领旧episode补偿；旧整数债仍按最早欠期支付，不因此扣住人身。

## 正常人物与存档入口

`named_membership_v1` 与原 `regional_life_v1` 显式共存。人物事项及当前对白直接显示当面已知邀请；发邀请或接受前展开完整条款，旧按钮绑定原来源、修订和真人。没有远地人名册或新管理面板。接受后原 `organization_accept_offer` 直接在该人物旁产生正式采购任务，后续买货、行旅和交付仍是原领域动作。

`game/tests/test_named_membership_player_flow.gd` 是中央一个联合Main节点的实际控件helper，不独立造世界。它从正常标题picker启动，保存“邀请未决”和“旧责未清、欠薪待释放”两类物理菜单银行，支持独立空标题继续、旧callback拒绝、玩家本人作答、真实卖粮续约及离职后普通生活。调用方提供精确包锁、原生库及来源身份，逐条正式命令和全世界/有效checkpoint对照由中央联合节点拥有。
