# Explicit diplomatic response author example

This independent 1.0 package adds diploreply::scenario.qingchuan_diplomatic_response. It uses the unchanged political_economy1.2 initial actors, offices, grants, resources and original city salary. The actual sect steward is given an explicit authored directive to accept only the named passage proposal after a real presentation. No scores or world facts are invented from the directive.

The ordinary Director still checks current authority and actual contact. An accepted proposal remains pending ratification; this package does not grant passage, pay travel reimbursement or enable another-person envoy reporting. Old civicecon scenarios remain available with their prior behavior.

Six-pack normal composition: STRUCTURE_VALID, no warnings or missing resources; digest recorded in provenance.json. Native/World/Main checks require the response-registration build and have not yet run for this new profile.
