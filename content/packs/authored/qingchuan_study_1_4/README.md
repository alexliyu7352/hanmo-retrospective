# 青川习业 1.4.1 候选补充：回气切磋与凝神授业

本版本在同一包ID `qingchuan.study` 下新增第五个独立场景 `scenario.breath_practice`。旧1.2、1.3作者目录不改；只能明确选择一个包版本。原四场景及全部旧定义保持原值，原四场说明见相邻1.3目录的README。

## 最小玩法入口

第五场沿用第三场的程禾、孟修、原地点、原四个人物、1820钱和原物品。程禾仍只有120钱、2份行粮、零普通技艺经验、未学武功、未装备剑甲；不赠剑、不预授回气技能、不生成新人物或钱袋。

同一孟修仍是原剑庭教习。新场仅将原教习服务挂载替换为 `role.sword_master_breath`：原资格、三门授业、普通课程、器械柜、短工、住宿、收费钱包和8钱切磋费不变，绑定说明回气规则的对白与独立切磋目标；本候选仅额外提供下述凝神课程。新场不会同时启用原、新两条服务；这不是新增职业或第二份任职。器械柜只使用对应的代表引用变体 `shop.sword_counter_breath`，仍指向原同一库存、钱包、地点及名称；新场不同时启用原柜台定义，不增加货物或另开资金账户。

玩家可从孟修原器械柜用正常交易买习用剑并装备，再当面交谈、选择切磋、确认8钱费用。已有半日开场规则不变；战术回合不额外推进世界半日。初始120钱可支付一柄原价68钱的剑和一次8钱切磋，余44钱，不需要测试充值。授业和普通武艺课程仍可按原入口另行选择。

## 已有回气模型的正式启用

仅新目标 `objective.breath_spar` 声明 `stamina_model: round_v1`。普通防御10、真正原地等待15、普通攻击实际正伤命中一次5、每次实际正伤受击3；一轮合计最多20、总气势最多100，出招费用先付。主动秘技不领取普通命中的5；倒地或已离场者不恢复。

这些值全部来自已经实现的个人战模型与正式05§5.4；本包不改算法、伤害倍率、AI、武器、旧秘技、初始气势或旧目标。原第三场仍采用旧目标；旧四场不会因新增第五场而被打开新规则。本候选另外启用DU01凝神，其他DU卡不在本片新增，不能把这场称作完整DU卡内容。

## 凝神候选：沿原学习与单心法配置链

依据03的DU01和05§5.4，凝神要求武艺一阶，实际修炼取得正掌握并配置为当前心法后，普通防御额外恢复5。只读当前单一心法，不因同时学会另一门而叠加；等待、主动守势、零掌握、未配置、资格不足、倒地或离场均不给额外5。现有剑、长兵、弓都兼容，攻击/防御倍率10000、移动修正0、费用0仅表达中性字段，不额外赠予旧敛息的增益。
