# 青川外交作者小包 1.2.0

新增 civicecon::scenario.qingchuan_diplomacy。原 1.1 两情景的全部字段深值保持不变，原发行包和已准备档案独立保留。本情景沿真实县署书佐、剑院管事、两侧 Office、既有道路与会面岗位，只追加四项具名专项授权。没有新增人、钱、粮或全权人物。

本人以原公职提出通行条款，再明确受领使者责任，沿实际行旅到剑院与合法代表会面，按唯一 Common Action 完成交接。本人自任不要求向自己返报；当前配置 return_report_required=false。对方明确接受仅到 pending_ratification，尚不产生通行许可或条约效力，也不表示 NPC 已自主决策答复。真正他人委任、返报和双方认可后效力是后继功能。

提议窗8半日、受领窗4半日、交接1半日、拟议有效期12半日、提前2半日通知是本例明确 provisional 作者参数，不是 GDD 已定政治数值、历史事实或全局默认。通行地点为现有剑院门前；其旧准入本来开放，不能将本例当作条约解锁效果证据。无额外经费和酬金。

本目录是作者源；正式 compose、安装、World/Session 与 Main 验收须使用中央共同冻结的外交模块版本。组件和 schema 门不等于该链已通过。
