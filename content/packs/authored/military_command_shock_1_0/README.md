# 主将去留

独立作者 hanmo.military_command_shock 1.0.0，情景 shock_watch::scenario.command_road，复用原溃军归路的人员、公库、编军和真实野战。无初始损失、溃退或震动事实。

显式 army_commander_once_v1：按每支实际军团入场前的形成/接任来源冻结其统帅。首次实际退离、溃退或阵亡只使该军仍参战且未溃退各部士气减10，本场一次；同侧盟军、场外统帅、普通部将伤亡不据此扩大。人物生命仍走原伤亡结算。

军事11需要完整10/9/8和原政治接任、个人康复前置。旧场景不追加空段。此包仅源码，正规compose、实际会战、冷银行和UI验收待集中执行。
