# 青川安民作者小包 1.1.0

新情景 civicecon::scenario.qingchuan_governance 复用 1.0 的既有真人、县署公库和家庭，新增安民规则及明确受领计划。原 1.0 作者目录不改；本版本内原青川署务情景也保持原字节值。

安民劳动6半日、公钱120、粟10、民心增加3+实际完工时礼学级且上限100，来源为正式06§6.8。新情景的民心50是可调整的中性作者示例初值，不是历史事实，也不是全局默认；受领窗24半日、完成窗12半日是本例明示开发配置。旧情景没有这些默认值或治理模块。

县仓书佐仍为原47岁真人和原公职；玩家可当面签发给本人，再亲自受领、沿原行动做满，最后按真实收据结算。向他人的委任仍待本人受领，不伪造NPC同意。现有 household.city/cohort.city 是8人的聚合家庭，唯一计划向原家庭钱包/库存转移120钱与10粟，不新增家庭、人、钱粮或可花余额。

劳动完成时冻结礼学与结果计划，容量阻塞时保持待结算。取消/死亡保真实进度和责任，只释放该契约未耗预留；比例结算和改派仍待后续正式规则。当前为作者源候选，尚未做正式compose、原生Session或Main验收。
