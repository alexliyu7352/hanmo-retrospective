# 青川署内托办（源码作者）

显式选择 political_governance_agencies/1。青川主事仍占原首职，代理委任不会任命副手、转移公职、预造安民任务或支出公共钱粮。

正常办理线：

1. 以原在任主事到青川公署；原徒弟须已真实满足成员新职责、成年、健康与同场条件。
2. 在原公署页选择 agency.qingchuan_relief，真实委任徒弟。12 半日内本人可接受或谢绝；48 半日的原任期/Grant范围内至多实际签发两份原安民邀请。
3. 沿已有成年收养请求与徒弟本人真实对白，完成原零资产自愿控制交接。它只切换操控者，不授公职或代理权。退出会话后，徒弟仍须亲自提交本次代理接受。
4. 代理在公署与执行人实际同场，签发原 commission.qingchuan_appease。该次仍生成唯一原 GovernanceAuthorityRecord；原模板需公库120钱、10黍。签发不等于受领或付款。
5. 由原执行人本人沿原治理入口受领，完整预约、6半日原工作、原赈济和民心后果全部走既有账。资金不足、旧任务占用或权限失效仍由原规则拒绝。
6. 原主事撤回、离职、死亡、期限或次数耗尽只停止新签发。已经受领的原任务按原连续性、实际控制与原钱粮结算，不因撤代理而自动取消或重新预约。

保留前驱作者原生前让职入口供对照，但本路径不需要执行让职。正式换职使旧代理失效，新首长须另行委任。
