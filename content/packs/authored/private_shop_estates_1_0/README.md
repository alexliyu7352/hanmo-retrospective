# 北門糧鋪與身後原約

這是 `estate_shop::scenario.private_shop_estate` 的正常作者輸入。固定選擇在 `content/packs/selections/private-shop-estates-1.0.0.json`，依賴 Qingxi 1.2、inland_fleet 1.2、military_witness 1.0（固定 c1a55ca）的原素材與軍旅入口。

## 生前入口

1. 原玩家先向北門三名不同的私人客戶，逐一實際接受、購貨、交付並返報原採購。原 Task 托管付款與原市場報價不改；作者沒有預置成功履約或商鋪。
2. 北營原市務官使用單獨的無錢貨法律 Grant，於原柜台查完整初冊並實際簽發該北門鋪位許可。玩家再依原租約開店，使用本人的原錢包補貨。
3. 玩家與秦澄在各自原崗位的本人 say 節點，分別作生前委託及接受。它只授該店身後舊責任的清算，沒有繼承、接新單、經營或公職權。
4. 若要保留一筆待清算的未交訂單，可向原三客戶之一另受領店單。實際預留全價仍屬原客戶；期限為受領後 240 半日，到期則沿原 Task 自動解除，不能假稱未交單仍有效。

## 身後來源

1. 玩家須先經秦砚原成年收養請求建立真實關係，再由秦砚本人在北營說明並接受身後生活接續。此同意只涵蓋控制秦砚本人的行動，不轉資產、軍職或店約。
2. 原玩家與莊內文書 `witness::actor.river_scribe` 必須沿原受領、借調、同行及成軍進入同一部隊。軍戰結果保持原規則；作者沒有死亡、受傷、親歷或返營結果，亦不保證某一人死亡。
3. 只有原玩家實際死亡，scribe 真正同部親歷、仍在世且合法返營後，這位原見聞者才可作發信人。其他死亡結果不能替代店主死亡。
4. 實際死亡後，沿原身後生活接續控制秦砚。由秦砚向 scribe 當面受領封緘文書、實交北門秦澄、回原發信人返報。信件本金與酬勞為零，原實物交接及時間成本照常。
5. 若要由玩家操作已收文書的秦澄，須再沿秦砚與秦澄原成年收養及本人零資產自願接續，先結束送信責任。此處同樣不授清算權；清算權只來自生前雙方原約及本人已收的原死亡文書。
6. 秦澄從已收文書頁進入有限清算頁。每筆未交、無活動交付的原店單，逐一明示取消，原客戶全額解除預留，已付／退款均為零。沒有批量自動取消。全部工資、租金、訂單及其他責任可證清結後，才可將餘款餘貨歸回死者原私產容器。
