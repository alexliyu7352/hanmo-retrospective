# 原入战资格顺序轮

显式选择 military_sequential_rounds/1，复用完整 Military14 入战资格与原轮次永久历史，无新兵员、资产或随机流。正常场景 sequential_watch::scenario.sequential_road 只复用 commanded_watch 的实际营地/部队与受职编军来源，不预造接敌或胜负。

统率/10＋步1弓0骑3按降序，同速轮转稳定ID。实际行动逐个落定，部队失能或目标即时结束后不补后手攻击，仍由原World提交这一轮半日。新溃退在自身排定行动才退离，原两次实际被堵与相邻俘虏来源保持。军官暴露按本策略每次真实兵损差分在下一行动前落定。

本策略仍复用原战法资源规则；05每轮兵法级资源恢复为独立后继。当前只具名源码及纯轮次门，正规Installed、完整World、自然接敌和GUI尚未验收。
