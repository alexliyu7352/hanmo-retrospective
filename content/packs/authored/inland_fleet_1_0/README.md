# 清溪舟师作者候选

依赖qingxi.campaign 1.2原作者与正式目录，派生riverwatch::scenario.inland_fleet。原人、钱粮、军职、人口服务与军令初态逐字段保留；只给所选实际演员明确full_sixteen_v1六项扩展技能（真实部队指挥者naval=300，其余=0）、原道路格换为本情景内河、新增4条有Common组织产权的实船和4个空货舱。未新增人、钱或货。

实船需要正常任职/军令/army_form后通过naval_form绑定原真实部队，不能作者预造fleet或战果。Hull数字是本情景开发参数：船体80、最低有效船员2、人数12、货重2000、战场移动3、原terrain成本/半日预算3000、naval最低等级1。只支持明确river与失能仍浮水方向，沉没/救生/漂失不在schema。

生成器 docs/native/system-battle-military/naval/build_author.py 保来源摘要与初态比较。当前模块/Schema注册仍是候选，尚未正规compose、Native或Main，不把本作者文件存在当作可玩水战。
