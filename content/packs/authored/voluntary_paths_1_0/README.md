# 生前自愿接续作者

场景 `livingpaths::scenario.qingchuan_living_paths` 沿原青川社会与真实旁支来源。首任先当面取得原旁支双方认可，再在单独的 `living_yes` 本人声明记录零资产生前接受；结束会面、原双方军旅及受托责任就绪后，才从原已接受方案换控。原死后许可仍使用不同节点，不能替代此项接受。

亲生路径沿原实际受议、生育、有限照护和真实年龄。新生原型仍 inactive，不预造活人、成年、关系或同意；成年子代可通过真实 Known 私人模板说出自己的接受或撤回。该自然多年链尚未运行。
