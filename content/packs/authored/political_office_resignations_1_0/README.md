# 青川属吏当面辞任

正常选择：`political-office-resignations-1.0.0.json`。默认本人许谦为原目录明确在任的粮务属吏，六十六岁；原首长仍在原首府。粮务辖区的空公库与首府公库各自独立。

1. 以许谦在首府当面提出辞任申请。申请只保存本人意愿，原职与 epoch 尚不改变。本人可以原地撤回，逾期也不自动离任。
2. 若需同一局逐人办理，可在原首长本人发言处正常办理成年收养，再按另一明确发言形成零私资自愿接续；结束会话后使用原 `family_continue_as`。作者没有预置关系或换控。此步骤仅切换受控本人，绝不授权公职。
3. 成为原首长后，在原首府双方真实在场且空闲时，当面明确批准或驳回。原首长须仍为申请时的同一任期，专项批准 Grant 必须有效。批准才调用原 Office 失效账，属吏职位变空、epoch 加一；驳回只关闭本申请。

成员身份、原 Task、已接受安民合同、债权及全部公私资产均不由辞任清除。换首长后原申请不能借新任签字，须本人撤回或待期满后重新申请。当前首片无 NPC 自动批准。

本包仅源码和作者输入；完整新局、亲属办理和辞任 World 链尚未运行。
