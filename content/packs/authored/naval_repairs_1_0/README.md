# 同舟修缮作者输入

独立场景 `shipyard::scenario.repair_patrol`，依赖原 inland_fleet 1.2 与 qingxi.campaign 1.2。原人物、军令、船体满值、配员、自然接敌和伤亡策略不变。每个新情景船舱有显式 8 木材、4 铁料备品，不从远方公库取料，也不在运行时生成补给。

只有原军团实际成舰、真实受损且当前统帅/船长/fit船员仍合格，才可沿军旅舟船页开工。原船队停驻两半日，预约并消耗 4 木材、2 铁料，最多修复 20；水上只能修到 40，返真实泊地可达原上限。取消、接敌或真实船员变化保留失败来源并返预约。NPC仅两位原南方统帅有同工法明示意图。

本作者包随 Naval3＋naval_repairs/1 完整闭包启用。SOURCE_ONLY；尚无本情景正式运行或自然捕获/修复银行。
