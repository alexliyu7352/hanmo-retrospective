# 军粮与守营

独立场景 supply_watch::scenario.supply_discipline 复用 Military8 北营康复原人物、真实粮额、医者和军令。没有预造缺粮、伤亡、逃散或接任，也没有新发钱粮。

显式 military_supply_attrition/1 仅使真实匿名可战士卒在连续第二个缺粮半日起，每半日按该期池子的2%向上取整逃散；原士气每缺粮半日减10。具名军官与亲兵不纳自动逃散。足额原供给中断连续计数，行军/编散不会用今天粮额重写过去。原人口token向其既有流民cohort交接，已付半日口粮不重发。

战中实际逃散先于原回合；原已交命令若因此失能，会留下明确取消原因而不重新选择AI攻击。旧军事1..8不开新政策仍保持原字节。SOURCE_ONLY，未正规compose或实际World银行。
