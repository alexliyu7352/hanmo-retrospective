# 旁支本人认可与条件接续

正规Installed作者扩展，沿原青川社会与经济依赖。原玩家程吏与程行客有显式共同父亲程伯元；初态只保存生身来源，认可及控制许可均为空。

1. 在本地已认识并实际在场的程行客处打开正式私人会话。
2. 听其本人认可声明，玩家明确确认，产生双方认可来源。
3. 另到本人接受声明，记录可撤回的条件控制许可。认可本身不代签。
4. 只有原玩家日后真实死亡且候选仍满足原处境条件，才能明确选择继续其原有人生。此作者没有造死亡、预设许可或交割财物。

保留原生育与有限照护条款。未来真实出生并成年者可通过叔伯对晚辈的显式私人模板另行认可；当前原型保持未启用。没有18年自然运行、死亡、动态模板或完整World通过声明。新声明不自动转移公职、遗产、职责或隐秘消息。
