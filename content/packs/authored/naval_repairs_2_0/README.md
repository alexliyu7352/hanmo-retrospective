# 公营船坞修缮

独立 `shipyard::scenario.public_dock`，依赖原 qingxi.campaign 1.2 与 inland_fleet 1.2。采用明确的入坞初态：四艘原作者船体20；没有预建编队、预约、工单或战果。原满船/免费实物作者与旧银行不修改。

原真人军团正常形成并登船后，在作者明确的南/北营船坞开工：两半日、3木材、原军团钱袋80钱、最多恢复20船体。材料与款项同时预约，完工在一个原Common recipe内消费材料并从军团等额支付原公库；取消、接敌、船员变化或服务经营权源改变时不付款并解锁原额。自修浮泊仍沿原实物工法/40船体上限，不远程购买船坞服务。

服务受益组织、原公库、工法与版本均显式声明。实际占领造成公库换主后，继任组织没有自动继承维修经营权；停止新开工，旧工单保原款项退出。军团初始、私产、粮耗、原随机战斗和军籍不变。

需完整 Naval4 + naval_repairs/1 + naval_repair_charges/1 与原舟战共同准入。当前 SOURCE_ONLY；本作者尚未正式 compose/Installed/World 验收，不称自然战后损伤或捕获通过。
