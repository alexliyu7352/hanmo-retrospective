# 青川与松门 1.0.0

正式内容包 `hanmo.local_society`，通过 `content/packs/selections/local-society-1.0.0.json` 组合。它延续本项目已有青川、粮行和剑场美术；旧 `qingchuan.study` 内容及版本不改写。缺失的声明图片须由中央 stage 从同 SHA 的已授权资源恢复，不能用占位图宣称美术验收。

两个可在正常标题选择的情景使用相同 `local_society_v1` 原生规则：初春供养与农忙练武。后者只调整地区供给目标、初库存和有界季节系数，不换时钟、资产模型或人物身份。人物固定为作者学徒；不支持开局覆盖其外貌。

## 可玩的因果链

- 青川县署与松门剑社分别持有真实粮库、采购预算及工资钱包。家庭钱包和私库归家庭身份；匿名村民与门人不重复包含具名人物。
- 每四个半日结算一次生产、口粮与工资。县仓书佐工资12钱，工资钱包初有8钱；松门师傅工资20钱，工资钱包初有7钱。未付部分保留为债，不凭推进补钱。
- 松门实际课程、休整与服务收费进入同一工资钱包；玩家付出的服务费能改变后续清偿。欠薪持续会产生请求结清、拒绝新职责和合法交接，已承诺的个人行动由原规则处理。
- 粮行是实际可售货源，玩家和两名具名NPC争用县仓/松门同一需求份额。接单冻结数量、预算、报酬与期限；采购与行旅使用原入口，交付通过场所近况的真实合同按钮完成。
- 青川与松门有两个方向各一半日的道路。对松门的采购必须有真实跨地运粮；未到货不算收粮。货主与采购预算仍由任务托管容器记录。
- 玩家有县署志愿练习的明确职务授权；同意范围只涵盖作者声明的本地民户，至多4人。转入训练会扣减原生产劳力，训练仍消耗实际口粮；完成成为预备状态，不凭空变成军队。

## 开发平衡参数

本包数字为 provisional，供首个联合体验节点检验结构，不是最终平衡承诺。单位：钱、件粮、人数和半日。青川8人/6劳力，松门3人/2劳力；基础配方每劳力每周期产1件粮，口粮每人每周期1件。初春系数10000基点；农忙的青川系数7500基点。初春粮食维持目标20/10件，单份采购最多4件，预算上限每件20钱、报酬每件2钱，期限24半日。

合法工资/口粮责任优先；库存不足会留下实际短缺。没有自动税收、隐藏财政补助、强制征募、死亡/迁徙阈值或通用后台战斗。需求消退和部分到货按冻结合同结算；未交付货物仍须真实清算。

## 开发验证边界

源Schema、显式引用/人口产权/供养劳力/授权/道路货源准入在作者流程验证。原生冷工厂只构造typed域，不调用GD世界工厂。实际导入、两经济周期、三同时间反事实、第二情景复用、在途存读与1280×900窗口体验由中央唯一联合节点执行；源码检查不代替这些验收。
