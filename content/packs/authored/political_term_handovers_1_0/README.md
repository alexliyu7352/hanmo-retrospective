# 青川后任首职生前交接（源码作者）

本独立版本保原后任提名制度，另选 political_term_handovers/1。没有预置收养、控制切换、任职、更职或双方政治意愿。

1. 原城务首任同程禾的真实成年收养与零资产自愿接续仍须原 say/Family 命令办理；原公职不会随玩家控制移动。
2. 原首任明确提出首轮生前让职，候选成为受控本人后在首府接受。此时原 Office 实际持有人、epoch 与交接事实成为本任唯一根。
3. 程禾在原首府与沈简同场，沿新“后任生前交接”页明确签发意愿。必须原专项 Grant 当时有效。
4. 程禾可通过本情景原沈简本人 say 完成第二次真实成年收养及零资产控制接续。换控后程禾仍持原 Office。
5. 沈简在原首府与程禾均可行动、原首任仍持同职同 epoch 且 Grant 未过期时亲自接受。原 Office 及 epoch 只此刻一次变更。
6. 本人谢绝或原首长撤回关闭该次意愿，不改变原任职；过期或后来换职不可复用。

可在真实就职后另行签发下一死亡继位提名；此前生前意愿不能替代死亡继位所需的本人接受、真实死因、实交文书与原空缺。

当前只提供源码与正规条款输入。行为、完整 World 与素材准入尚未运行；不以 schema/link 校验代替自然可玩链。
