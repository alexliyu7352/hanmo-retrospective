# 军中明命

本情景沿原“同舟故人”的真实客舍借调、编军、编舰与舟战。史墨初态不在 fit，没有军团或伤亡；仍须玩家受职受令后沿 army_pledge 借调，以 north.work_detail 为首部真实 ArmyForm 编入。原 naval=100 保留，船只 crew、载重、路费与其他条件继续由原规则核。

史墨在初态已经持有北方的两项专项公职 Grant。仅当真实原部/军统帅已亡，自己仍是本军具名 fit 成员且同原舟舰 binding 时，才可面授、本人接受并执行接部；成为实际部将后再另行签受接军。原作者 NPC 策略按正常公平复评提出这三种命令。死亡本身不产生 Office、Grant、兵员、资源或继产。

不保证随机死亡或幸存。第一步之后原军团仍可能失能，该中间态需按显式 pair 冷存。是否能实际返航还须原航行技能、存活船员、军粮路费及战场条件；接替不会重启原死者已失败的军事任务。
