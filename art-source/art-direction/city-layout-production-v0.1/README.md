# 城市独立分层素材 v0.1

沿已认可的市场效果参考制作。该参考只提供画风、光照与建筑氛围；没有把整幅参考图贴入样板，所有街区均由真实独立PNG和布局数据渲染。

资源保存在 `game/assets/art/layered-city/`，路径和ID以 `game/data/presentation.json` 为唯一资源清单。首阶段七张：完整地面、酒肆、粮铺、布帛铺、粮铺施工变体、客舍和树。实际是四种建筑；粮栈明确复用粮铺形体，不算第五种。客舍为独立院落形体。

`sources.json` 保留生成工具、提示规格、参考来源、像素规格、透明性和原始PNG摘要。图片使用内建 ImageGen，生成后不通过程序涂抹接缝；真实Godot以同一图层数据缩放和合成。新素材均待用户美术评审，不把程序检查记作画风通过。

当前状态：独立样板可运行；标题、两种布局和占地冲突已修正。Godot 4.7.2 真图形进程输出十帧，50项定点检查通过。证据见 `verification/city-layout-system-20261006/`；新美术仍待用户评审，不等于正式城域已整合。

入口：`game/demos/city_layout_lab.tscn`。检验按钮只改本次显示，没有经营、身份、工程进度或存档含义。点击建筑或纸签打开同一实例的场所外观近景；该近景不是已实现的室内经营玩法。

第二阶段新增一张可重复地面材质，共八张PNG。独立街段编辑功能已由真实拖放和Godot画面验证；道路横向砂色条带与石地、建筑透视不一致，路面融合未通过，不能作为正式道路美术。后续在同一系统内统一透视、材质及交叉/门前衔接。
