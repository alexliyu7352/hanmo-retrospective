# 场所卡片备选 v0.4

日期：2026-10-03。状态：**单排堆叠场所卡片效果图，待评审**。

用户指出参考图在卡片多时采用堆叠：保持卡片自身宽度，通过缩小横向间距容纳数量。本版据此修正 v0.3 的窄卡平铺，不恢复双排、36处或分类搜索分页目录。

![单排堆叠场所卡片](market-cards-ui.png)

## 堆叠规则

- 卡片是完整的竖幅场所绘画，名称沿露出侧竖排。卡片数量少时自然排开，数量增多时缩小横向间距，让前牌覆盖后牌的部分图画，保持卡片本身的宽度。
- 各卡保留可辨认名称与可点击区域，不能被完全遮住。示例的左侧酒肆卡片置前、略抬高并完整显露，其余保持堆叠；焦点处理不把整排展开。
- 卡片仍是进入具体场所的入口，随后与真实在场人物交互，不增加“前往”确认或无来源服务菜单。
- 图中十张只说明排布，不是全城固定数量、最低数量或新增设施承诺。实际列表由当前街区的既定真实内容决定，不补假卡片或凑数店铺。
- 新建、拆除、迁址、停业及修缮更新对应入口。背景只表达氛围，精确规划、升级和权限操作继续由独立管理视图处理。
- 叠压也须保证名称和点击区可用；窄窗、大字号、绘制层级和焦点切换仍需实际程序验证，不靠无限缩间距解决所有尺寸。

## 图中内容

从左到右为南市酒肆、陈记粮铺、许氏布庄、周氏铁铺、李氏药铺、东来客舍、陶器铺、木器铺、皮革铺、南市仓房。酒肆为黛青焦点，周氏铁铺保留“修缮中”红签。保留玩家资料、地点／找人、右侧同行、返回城域及产业／地图／手记／系统入口。
