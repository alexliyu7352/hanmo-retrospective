# 场所卡片备选 v0.2

日期：2026-10-03。状态：**已退回，当前方案见 [v0.4 单排堆叠卡片](../card-fallback-v0.4/README.md)**。

用户指出36处的规模不符合当前游戏规划，并要求恢复一排竖向图卡。下文和图片仅保存旧版过程，36处、三页、两排及分类搜索分页均不作为现行要求。

用户指出 v0.1 单排六张大卡片容纳场所太少。本版保留街区立绘，将底部改为两排六列的紧凑卡片，并直接展示分类、名称搜索和翻页。

![场所卡片 v0.2](market-cards-ui.png)

## 容量与操作

| 项目 | 设计 |
| --- | --- |
| 默认宽屏 | 每页十二处，两排六列；左缩略图、右名称与用途或状态 |
| 图中示例 | 共36处、1/3页；上一页禁用，下一页可用 |
| 分类 | 全部、食宿、商贸、工艺、医药；不限定真实场所数量 |
| 搜索 | 按名称查找当前街区全部可显示场所，再分页 |
| 同类多店 | 南市酒肆与北巷酒肆分别出现，绑定不同真实场所 |
| 修缮状态 | 周氏铁铺灰色并标注修缮中，暂不可用示意 |
| 窄窗与大字号 | 减少列数并重算单页容量，不靠缩小文字强塞十二张；待验证 |

首排：南市酒肆、陈记粮铺、许氏布庄、周氏铁铺、李氏药铺、东来客舍。第二排：陶器铺、木器铺、皮革铺、肉铺、菜蔬摊、北巷酒肆。名称和36处总数均为演示数据，第二、三页未单独出图。

十二处仅是该宽屏构图的单页容量，不是城市或街区场所总量上限。总数与页数从筛选结果计算；新增、迁址、拆除、停业和修缮更新对应对象。卡片本身是访问入口，不增加城内导航、时钟或“前往”确认。

街景作为氛围绘景，实际场所清单以数据和卡片为准；角色权限和独立规划、管理视图沿用既定备选方案。

## 检查与边界

实际输出 **1672×941 RGB PNG**。已目视检查十二张卡片、两家酒肆的区分、分类入口、搜索框、分页数字、修缮状态及返回入口；格式、尺寸与摘要已核对。

当前仍为 ImageGen 整图效果图，未拆层；搜索、筛选、分页、动态场所数量、响应布局和 Godot 接入尚未实现或验收。暂定 2560×1440 源图规格未完成。
