## 交互与权限

- 直接点击区域进入局部，独立场所可直接访问；门禁或关闭说明附在入口。不设城内导航线、当前位置图钉、日历时钟、步行耗时、通行费用或“前往”确认面板。
- 地点与找人索引是辅助入口。找人依据已知住址与消息，不能显示未知实时位置。
- 旅人可以经营自有或获授权的产业；城主规划辖区公产并授权属官；官员按受托对象、操作范围及预算办理事务。公职不自动赋予拆改私人住宅的权利。
- 空地、拟建、在建与已建建筑须可区分。基础、木架、材料及施工人员是城景的一部分，工程细节在相应面板中展开。
- 新建、改建和升级需要检查产权、地块边界及道路接入。当前展开的是新建和升级；完整布局移动、合并与拆分操作尚未展示。
- 工程工期属于建设信息；世界行旅和实际活动的耗时继续按各自规则处理。

## 检查与边界

三张 PNG 均为 **1672×941、RGB**。已目视检查区域标记、河岸空地、营舍施工、货栈拟建预览、官仓武库选中效果及角色权限和操作面板。文件格式、尺寸及 SHA-256 已核对。

人物、体力、资金、材料、劳力、工期、授权额度和 45% 进度均为演示数据。标记与个别建筑的精确对应仍需按最终地块校准，面板遮挡与标签密度仍待评审。布局改建、损坏、停工、完工和旅人产业的完整面板尚未出图。

当前素材为未拆层的静态构图目标，未完成暂定源图规格，也未实现按钮交互、自由布局、权限校验或经营结算。未进行浏览器、Godot、窄窗、大字号或游戏功能验收。
