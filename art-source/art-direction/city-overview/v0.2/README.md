# 城域总览与地点选择界面 v0.2

日期：2026-10-03。状态：**已退回修订，历史过程记录；由 [v0.3](../v0.3/README.md) 接续**。

用户指出城中导航和时间属于过度设计，且本图未展示空地、施工、实际建设面板及不同身份的经营权限。以下为本版当时的设计与检查记录，不作为现行交互要求；原图与提示词保留用于对照。

用户指出 v0.1 只有城景，没有按游戏设计显示对应 UI，因此不能算完整界面。本版以原有城景为底图，补齐当前浏览状态需要的常驻信息、索引、同行和行动入口。v0.1 保留为背景研究记录，不计完整界面交付。

## 画面对应设计

| 区域 | 内容 | 对应设计 |
| --- | --- | --- |
| 左上 | 当前人物、身份、体力 | 第 04 章探索常驻信息 |
| 顶部中央 | 地点、日期时段、游览与经营规划入口 | 第 04、10 章 |
| 右上 | 一条当前重要期限 | 第 04 章消息与活动 |
| 左侧展开索引 | 地点、找人、搜索、收起；九处地点及开放、通报、受限或门禁状态 | UI-08，地点与索引等价 |
| 场景 | 当前位置、选中的市、路线预览 | 城内外连续访问；路线为示意 |
| 右侧 | 同行 2，护卫与随从的独立头像 | 第 06 章同行单列；无公共大底板 |
| 底部中央 | 市的内容、预计耗时、费用、前往市场、查看场所 | 先看条件与代价，再确认行动 |
| 左下及右下 | 出城、地图、手记、系统 | 返回与全局入口 |

角色名、日期、体力、期限、同行人数和一刻步行时间均为演示数据。找人应按已知地址与最后消息展示；经营规划入口不授予全城建设权。头像只作既有画风参考的界面示范，未恢复人物部件生产。

## 目视检查与边界

已检查最终 PNG：上表中的入口与状态均可见，中文主要标签可读，目的地与主操作统一为市场；当前标记位于南门外地面，移除了其南侧多余路线。高亮改为较克制的青色，城景主要分区保留。路线和选中边界仍是绘制示意，未绑定精确热点、遮挡和游戏寻路，不据此证明路径算法或碰撞正确。

实际输出 **1672×941 RGB PNG**。这是静态目标图，未拆层，未完成 2560×1440 源图规格、真实按钮交互、浏览器布局、窄屏和 125%／150% 字号、Godot 验收。找人、经营规划和消息抽屉目前在图上有入口，展开状态仍需后续目标图。
