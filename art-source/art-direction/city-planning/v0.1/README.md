# 城域结构规划 v0.1

日期：2026-10-03。状态：**玩法空间提案，待用户评审**。

以虚构示范郡城验证城内与近郊一体、官署与私宅分别访问、市场容纳多个经营场所、建设改变实际空间的设计。不是特定历史城市复原，不是最终场景美术，也没有接入 Godot。

## 文件

- `city-plan.png` / `city-plan.svg`：现状与三处规划用地。
- `city-plan-built.png` / `city-plan-built.svg`：同一布局的建设后示意。
- `city-plan.html`：下载后打开的独立访问路线与建设状态预览。GitHub 文件页不会执行 HTML。
- `city-plan.fragment.html`：Page 嵌入预览的原始片段。
- `city-plan-data.json`：10 个访问地点、路线和 3 个建设示例。
- `build_map.py` / `preview.template.html`：可复用的图形生成源文件。

地图按同一套坐标生成；P1 旧仓改商铺、P2 增建营舍、P3 码头货栈与商铺只改变对应地块。示例不表示游戏只有三个建设槽，后续可调整地块、院落、道路与城防；权限、时间、费用及搬迁等规则仍需具体设计。访问路径是人工绘制的说明线，不是寻路实现，不表示实际距离或耗时。住所和服务位置不等于人物当前所在位置。

## 重建

运行 `python build_map.py` 生成 SVG、JSON 和两种 HTML。PNG 由 Inkscape 导出，例如 `inkscape city-plan.svg --export-type=png --export-filename=city-plan.png`。渲染机需安装 Noto Sans SC 或其他中文字体；本次使用的公开字体来源记录在 `font-provenance.json`，字体二进制未纳入仓库。

## 验证范围

两张 PNG 已实际打开检查，修正河道越界、地图注记拥挤与码头规划用地范围。两个 SVG 通过 XML 解析；预览脚本通过 Node 语法检查，选择框与 10 个地点数据一一对应，规划数据为 3 项。无可用浏览器，未完成浏览器内交互与窄屏实测；未进行 Godot、真实寻路或经营数值测试。静态图与逻辑检查不等于美术验收通过。
