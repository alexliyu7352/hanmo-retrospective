# 汉末人物组合试验 v0.1

**美术验收未通过。** 本目录保留失败试验，不能作为正式人物资源。当前结论见 REVIEW.md（未公开） 与 review-status.json（未公开）。下文为原试验范围和复现方法，程序检查通过不代表美术质量通过。

本包把生成的美术纹理拆分为实际透明图层，通过固定位置与遮罩合成人物。它用于检验人物美术的可组合性，不是最终捏脸界面，也未接入 Godot。

双击 `index.html` 可打开便携预览。预览内嵌经过压缩的纹理；原始 PNG 在 `assets`，原始精度的试验图层在 `exports/layers`。`full-quality.html` 读取原始 PNG，需要在本目录启动本地 HTTP 服务后打开，例如 `python3 -m http.server 8000 --bind 127.0.0.1`。它不调用外部服务。

## 本轮范围

只覆盖成年男性、适中脸族、固定朝向、同一半身姿态与一种肤色。两个五官方案通过眉眼、鼻、口三个槽位组合；眉与眼暂时成组。平静和微笑使用对应五官变体。发冠、衣身各两组，胡须为无须或短须。

| 图层 | 导出 PNG 数量 | 含义 |
| --- | ---: | --- |
| 头脸底层 | 1 | 固定骨相与本组遮罩 |
| 眉眼 | 4 | 两种眉眼各有平静和微笑变体 |
| 鼻 | 2 | 两种鼻型，不随表情切换 |
| 口 | 4 | 两种唇形各有平静和微笑变体 |
| 胡须 | 1 | 短须；无须时不绘制此层 |
| 衣身 | 2 | 日常、行旅，包含本姿态的衣领、身体与手部 |
| 发冠 | 2 | 束发、布巾，整组替换 |

16 张独立层统一为 512×768 透明 PNG。`exports/layers/index.json` 给出层序及各选件，`manifest.json` 记录画布、裁切与适配信息。运行时不自由移动五官。源图集中的第六张戒备脸是未接入的备用素材，不属于本轮支持的表情。

128 是本样板七组选项的全部配置状态数，包含换装、表情等同人变化，不是 128 个独立身份，也不是人物库的质量指标。

## 制作方式与复用

源图集由图像生成工具制作。眉眼、鼻、口图层从同一适配族的原始纹理取样，经固定柔边遮罩导出；它们确实作为独立图层参与运行合成，没有把整幅多人图作为合成结果。相关取样和遮罩代码保留在 `renderer.js`，便于检查和重新导出。

同一套头部定位用于两套衣身。衣身预留的头部区域清除原图中的极低透明度残点；颈口使用统一遮罩，发冠有固定的资源适配位置。眉眼、鼻、口还受头脸轮廓遮罩约束，防止伸出脸部轮廓。头像在人物合成后，从同一安全区域裁出 88 和 96 像素图，不单独重绘。

`assets/dedicated-target.png` 是以实际合成人物为参考生成的专绘姿态目标，供美术比较。它是整幅图，不具备本样板的任意换装能力。`exports/portrait-4.png` 保留对应的真实组合版本。

## 验证结果

`qa/verification.json` 保存本轮实际运行结果：128 个配置均可渲染；换装保持领口以上脸部像素一致；表情不改变头形、鼻、衣身、发冠和胡须层；三个五官槽位相互独立；五官不越出头脸轮廓；序列化后可恢复相同像素；88、96 像素头像来自同一合成结果；原始纹理具有真实透明通道。

这些检查证明当前取样范围内的素材合成行为，不等于美术定稿。大图的肤色过渡、发冠轮廓和颈口还需美术评审。轻微唇形差异在小头像中较弱，人物辨识仍要结合骨相、眉眼和稳定外貌特征。

浏览器交互及响应式排版没有完成运行验收：当前环境没有可用的 Chromium。`verify-viewer.cjs` 保留相应验证用例，安装浏览器后可继续；没有把这项记作通过。Page 内嵌渲染与 Godot 运行效果也尚未验证。

其他性别或脸族、体型、年龄连续性、儿童比例、肤色联动、眉与眼分别替换、前发后发与冠巾独立遮挡、多姿态、完整表情及存档接入都需后续扩展。本包的可操作预览是素材检查工具，不是 UI-04 的正式设计。

## 重建与检查

需要 Node.js 及 `package.json` 中的依赖。已具备依赖时，可依次运行：

```bash
node render-sample.cjs
node --expose-gc verify-sample.cjs
node build-viewer.cjs
```

`--expose-gc` 用于大批量图像检查中的临时内存回收。浏览器已安装时再运行 `node verify-viewer.cjs`。这些脚本仅操作本包，不更改游戏仓库。

中文预览字体为 Noto Sans SC 的字符子集，许可见 `qa/OFL.txt`，来源为 Google Fonts。全部生成提示及素材来源说明保存在 `prompts.json`。
