# 个人战环境层 v1

本组四张图均由内建 imagegen 编辑既有原画生成，原生成字节保留，未由Python或SVG替画。每张 `*-candidate-01.png` 都有对应prompt；`provenance.json` 保存原工具路径、尺寸、SHA256、导出与实际审核状态。

练武场按零障碍整理；河渡保留原两真实障碍，以独立河水和树根岩石层随原矩形绘制。原背景不删除，也不根据新图更改战斗几何。

源图与运行导出同字节，像素审核通过的是这些环境层。完整控件适配、局部无头证据、正式viewport未验边界及中央entry候选见 `../../../docs/presentation/personal-field-environments/INTEGRATION.md`。
