# F0.4 美术试验来源

本目录为本轮生成的概念图与临时场景构图工具。概念图不是运行截图，其内置版本号、编辑器画面、性能和平台文字均不能作为工程证据，也不应当直接作为完整游戏界面使用。

生成输出没有满足“独立、无UI的室内背景”要求，因此正式内景原画仍未完成。运行包目前采用明确标注的几何室内构图样板、生成街景的有效裁切和人物头像裁切。它们用于检查场景尺度与人物交谈位置，不冒称最终美术质量或严谨汉代建筑考据。

`game/assets/art/manifest.json`列出每个运行资源的来源、裁切坐标与状态。程序工具不包含字体；如本机存在有权使用的CJK系统字体，仅将城门示意名称栅格化到图像，不分发字体文件。
