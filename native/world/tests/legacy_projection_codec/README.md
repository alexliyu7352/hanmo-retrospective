# Legacy codec golden

`legacy_golden.json` 是明确手写的解码合同夹具，不声称通过旧全Schema或来自真实游戏命令。它用普通JSON保存可读源，专测逐值加同一冻结wire标签后提交生产解码器；原整数/String/bool及数组顺序保持区分。

覆盖五记录、完整owner/lot/inventory扩展、缺日期、零预留、原序参与者、目录未激活领袖/原型、Actor与actor_creation Fact同ID、已完成任命Fact而无Action、disabled缺历史Fact及deferred coverage。实际GD工件另由A导出后接同一解码入口，不用此夹具代替真实来源。
