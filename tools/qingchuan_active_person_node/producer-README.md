# 青川1.8实际本人行动生产者

本节点只验证当前真实产品接缝。`producer.py`读取中央标准stage manifest，核固定Godot及原生库SHA256，在新XDG中启动真实Main；不覆盖stage配置、世界、存槽、人物、教师或经济数值。源码stage和导出包是不同证据，当前仅headless控件流程。

`producer.gd`复用现有标题与物理存档控件基础驱动，但覆盖生产流程，不运行旧两人创建矩阵或本人115导航矩阵。正常选择沈蘅并保留原貌，从本章真实院前出发，经地图到松门。原岗位工作、当面货单、数量控件、装备、原武学和切磋全部发送当前可见按钮的原信号。学费不足时，先取消原报价，再正常做一份原工作，重新当面核价。不预热隐藏报价、补发遗漏确认或直接提交世界命令。

原始证据目录为新建输出目录，已有目录拒绝覆盖：

- `binding.json`：中央stage、源码、引擎、SO、catalog、driver身份和独立XDG路径。
- `produce/initial-world.json`、`expanded-catalog.json`：正常选人后的原世界及真实已展开完整目录。
- `produce/steps.json`：当前可见按钮、文字、路径、原交谈、来源与本人命令上下文；关键步骤另保双方钱包、库存及本人本领的有限前后快照。
- `produce/commands.json`：生产`command_completed`信号的原回执及来源。信号发生在新frame到达前，瞬时上下文可能如实为`StalePreview`，不能从该值伪造actor信封；消费者应与真实history/results交叉核验。
- `produce/equipment-checkpoint.json`和`equipment-bank-*`：购剑换装后的正常菜单物理存点及只读原件副本。
- `produce/save-manifest.json`：最终或失败稳定点的bank目录、每个原文件hash、PID、source、actor、action、interaction、personal battle及raw路径。
- `produce/saved-world.json`和`saved-appearance.json`：最终稳定点完整世界及外貌的原序列化字节；`saved-presentation.json`保存实际正式半身和头像资源输入。
- `report.json`：进程真正退出码、超时、stage源未变、原bank身份；退出码或断言失败均不得盖成完成。

生产者正常存档并终止进程后，才将最终manifest交独立consumer。consumer复制完整银行到另一XDG、保持同profile，从正常标题继续；生产者原件保持不变。未到切磋规划期时，manifest明确标为真实阻挡，不能称完整链已通过。

早期driver接线失败原件保留；不把原生没有`age_years`、有限地点投影不含`settlement_id`、货单默认库存数量、真实动态价格或菜单开闭判断当产品缺陷。正式结果以中央保全的实际终态回执为准。
