# 07｜完整人生道路与结局详细设计

**基线：总体设计第7、18章。决策：I01—I02、I12、I41、I46。**

仕途与商铺见04，军事高位与治理见05—06。本章补齐豪侠、水上人生以及四条求道路线的规则，不把后续目标删成一句“以后再说”。**豪侠/水上主要在P2开放，求道独立后期在P3完成；P1不以基础服务冒充这些职业已经可玩。**

## 7.1 共用职业合同

主要组织任职占一个槽：政治势力、商旅组织、豪侠组织、水上组织相互排他。自由贸易、私人铺位和求道活动不是额外任职。加入新组织前展示旧任务、物资、保密/恩义承诺和解除方式。

`CareerState`记录职业代码、阶段、资格成就集合、组织/私人事业ID、已完成里程碑；阶段从客观成就派生，不能单靠重复点击“申请晋升”改变。求道事业采用`Institution`：所有者、据点、类型、等级、公共/私人资源、职员/学生、课程或订单、开支、开放状态。复用店铺库存、任务与时间，不为每个职业开发独立经营引擎。

从一条路线离开，不删除已学技能、合法私产和人脉；公开背弃仍影响相关关系。只有当前正在执行的行动与地点约束限制兼修，职业不是禁止其他生活的技能锁。

## 7.2 豪侠组织

组织层级：受托者 → 可信成员 → 领事 → 组织首领。进入需完成一项地方护送/救援、组织信任≥30；领事需履约5次且覆盖护送、探听、救援三类，信任≥50、相关技能至少2；首领需组织支持≥60并完成一次组织危机事件，而非花钱买头衔。

任务使用信息、人员、交通和合同：探听只产生消息条目，不直接改变敌方位置；救援可以交涉赎回、护送脱险或在明确战场中突破。成功条件为实际人或物安全抵达，杀敌不是唯一答案。人员占用与公私物资仍用共用规则。

探听行动耗2半日，费用40；线索充分度由消息来源与任务条件计算。成功分`30+10×谍报级+floor(智谋/5)+关系辅助0—15−防备0—40`，≥55获得可靠位置报告，35—54只得旧位置/时间，<35未获有效情报。暴露风险独立：明确的高警戒区域基线20%，谍报每级减3百分点，最低5%；非敌对公开询问不制造随机通缉。暴露后取消隐藏接触并影响具体组织关系，不让全世界同时知道。

领事最多同时安排3个小组，每组有实际领队、参与者、目标、预算和路线。首领安排成员职责与承诺优先级；拒绝伤害无关人物的委托可以保留信誉但放弃报酬，不用一个全局善恶值抹平雇主差异。

阶段结局“乡里所托”：10项有效履约、至少3次和平完成高风险任务、两处据点关系良好。组织结局“众人相从”：组织成员≥8、无未清重大违约、完成危机事件，可继续作为首领活动。数值为试玩起点。

## 7.3 水上组织与船队

入行 → 独立掌船 → 船队领事 → 舟师/航路首领。必须区别于陆上商人的改名：水路可达性、船位、载重、停靠许可、船员、季节通行和船体状况决定行动。

`Ship`字段：id、owner、所在港/route、容量、船体0—100、船员当前/最低、速度、assignment_id、维护状态。初始两船型：小舟容量60/船员5/速度100，大货舟容量180/船员15/速度80。抽象单位，不提供真实造船教程。船体<30禁止远航；每完成10半日航行损耗5，停靠维修耗2半日、木材3、钱80恢复20。

同一船只只能属于一个有效航行任务；货物+人员占用不得超过容量。船员不足不出航，风浪使速度下降而不是无提示把玩家直接击杀。航线受阻可改港、等待或原路返航；油漆水面的陆路图不算水上玩法完成。

船队任务包括运输、护航、救助、封锁和军用调拨。商业与军用合同明确所有权与支配权；船员、船舶、货物使用同一世界位置。小舟可走浅航道，大船需要深航道；跨港运输必须实际消耗时间和费用。

水战复用05部队战并增加水格、航向转弯成本和船体：每部关联船组，水战技能替代步骑技能；普通舰载攻击先造成船体压制/人员损失，船体0且不能撤离时触发被俘/弃船结果。首次完整水战只需一套水域地形与两类船，不制作海洋物理模拟。船体攻击基础`10+3×水战级`，转向90度消耗1移动点，逆流成本+1；火攻不在首个水战扩展中增加未经定义的真实燃烧模拟。

阶段结局“往来无阻”：完成5次跨港合同，至少2种通行条件，合法自有一船。后期结局“江上之主”：掌握3条实际航线、船队连续30日收支非负、完成一次护航或军事危机。航线掌握来自停靠许可与组织关系，不是购买地图上的一根线。

## 7.4 武学：师承、挑战与传授

完整流程：入门学习 → 掌握一系 → 接受挑战 → 开馆/授徒 → 形成传承。技能等级不等于武学事业阶段，获得所有攻击卡也不会自动成为宗师。

入门可在公共设施；精进需要至少两位不同教学来源或两类实践考核，避免唯一NPC死亡锁死路线。掌握一系需相关技能3、三张同系本领、三次不同对手/规则的挑战。对手技能和流派影响考核，不要求真实历史名将一定在场。

开馆条件：武艺3、声望≥150、合法场所、钱800及100运营金。每半日传授最多2名学生，教师被占用，学生每半日得20基础经验，不能点击收徒立刻复制全部技能。收费每生每课20，场所日费3，收益来自实际课程。教师不在时暂停高级课程，合格代教最多教到自身等级。

挑战类型：位置考核、限制秘技、保护对象、不同武器对局，均用05规则。不提供独立动作引擎。连续切磋同一个低等级对手不会累加“不同挑战”成就，但仍可练习。

结局“自成一家”：主技能4、至少五项同系本领、三名学生各达技能2、完成一项理念选择事件。结局不要求杀死其他流派人物，也不授予无条件最高伤害。之后可继续授徒、旅行或任职。

## 7.5 名士与学问：讲学而不做知识问答考试

访学 → 能立论 → 开席讲学 → 门生与地方影响。核心材料是游戏提供的文献和事件，不要求玩家预先背诵三国史。技能以礼学、辩说为主，研究文本有稳定文献ID和所提供的游戏论据标签。

研究一篇需4半日，消耗纸墨类抽象费用40；完成获得该文本见闻与一条论据，不能刷同一本重复增加文献数量。论据在礼议中提供上下文选项，不直接把所有请求变为成功。

讲学开设条件：礼学3、辩说2、三类不同文献记录、钱600场所费。每半日一场，最多3名学生/听众组；每场给实际参与者经验，人物位置与时间真实占用。地方调解作为事件任务，须考虑各方承诺；偏袒会改变相关关系，不用万能“魅力判定”洗掉利益冲突。

结局“桃李成荫”：至少三名学生礼学2、完成三项地方争议/教化事务、讲学累计20场。被征辟可以接受或拒绝；拒绝出仕不封锁结局。不引入全国教育经营或书院联网排行榜。

## 7.6 医者：纯游戏化医案与医馆

学习 → 普通医案 → 疑难医案 → 医馆/救助 → 传授。全部医案是虚构标签与资源匹配，文本不得输出真实诊断建议、真实处方剂量或现实操作步骤。

`Case`包含patient_id、fictional_pattern、severity1—3、已知线索、护理/用材选项、疗程、费用承担、结果上限。游戏线索可为“奔波疲惫”“伤后虚弱”等叙事状态，具体药材仅作为抽象道具编号。结果通过医术和信息完整度决定，不由玩家在互联网上查真实医术才能破解。

观察耗1半日给线索；选择支持、调理、专门疗程三类抽象方案。适配分`40+10×医术级+线索完整度0—30−严重度×10`；≥60按全疗程完成恢复，40—59延长2半日，<40需转诊/补充观察。不会把错误选择变成现实药方教学。高危剧情另明确风险，普通低级病例不随机杀人。

开医馆需医术3、五项不同合格医案、钱800场所费与200运营金。床位3，每个病人实际占位和时间；每日消耗护理物资，资金来自收费、赞助或玩家自付。无钱病人可减免费用，影响医馆收支与声望；不能同时把减免金额算作收入。

结局“济人有术”：三类严重度医案各合格、完成一次区域救助、至少一名学生医术2。救助物资要真实从市场/组织转入，病患结果更新真实人物状态。医术技能早期作为学习/服务出现，不代表P1已完成上述经营。

## 7.7 匠师：材料、订单与可控质量

入门工艺 → 稳定作品 → 作坊 → 名作/传承。制造只采用游戏材料与品质数值，不提供真实武器制造工艺。

`RecipeDef`：id、产品、抽象材料列表、最低锻造级、基础工时、设备等级、品质上限、可选工艺标签。`CraftJob`：任务ID、材料所有权、已消耗材料、已完成半日、熟练度快照、质量结果、订单引用。

开工时预留全部材料，第一半日消耗基础材料；取消后返还未投入材料，已投入部分转成回收材料（50%向下取整），不把完整原料和成品同时发回。成品仅在工时满足后生成一次。

基础品质`40+8×锻造级+5×设备等级+材料适配0—15+操作成绩修正0—10−赶工罚分0—20`，限制在配方允许区间。普通、良、精三档为<60、60—79、≥80；达到“名作”还需特定配方/经历且品质≥90，不能用重复随机按钮无条件赌出。赶工时间×75%但品质−15，确认前说明。

开作坊：锻造3、完成5个不同订单、钱1000与合法设施；P3初始1工作台，可通过投入700扩为2台，每台仍需实际人员。军用与民用订单共用库存和工时；人员不足时不能两台同时以同一师傅效率运行。

结局“器以传名”：完成三类不同用途高质量订单、制作一件满足条件名作、培养一名锻造2学生。不是积累最大的战斗伤害就算匠师通关。

## 7.8 阶段结局与终局

`Milestone(id,conditions,claimed_tick,world_summary_refs)`。满足后排队展示一次回顾，奖励与图鉴记录原子提交；选择继续不改变世界，观看第二次不再领奖。

| 结局类型 | 时机 | 后续 |
|---|---|---|
| P1仕途 | 领队资格/独立考核达标 | 可继续已有任务，超出职位明确版本边界 |
| P1商旅 | 开业10日、2订单、净收益200 | 继续经营 |
| P1见闻 | 12据点＋6次有意义交往 | 继续旅行或转换人生 |
| 职业后期 | 对应本章事业目标 | 可继续，无强制统一任务 |
| 主动退休 | 玩家明确选择并二次确认 | 生成终局存档，允许读取退休前手动档 |
| 高风险死亡 | 明示风险且对应规则生效 | 结束此人人生，不自动继承到子代 |
| 自然寿终 | 完整版本选择开启；年满70后年度检查 | 开年前提示晚年阶段，生成回顾 |

完整版本自然寿终年度风险基点`min(8000,300×(年龄−69))`，70岁以下为0，仅在游戏年界检查一次，属于寿命玩法参数，不是人口史学模型。P1不启用自然寿终随机终止。便利设置可关闭主角自然寿终，不影响一般成就；历史人物专属终局事件仍需明示且满足状态，不按历史日期强制复活或杀死。

婚姻与结义通过双方意愿、合法身份和事件建立关系事实；婚姻对象都为成年人；不做配偶装备数值系统。第一轮完整产品不加入生育养成、跨世代继承或家族树经营。回顾来自实际经历记录，运行时不调用大模型编造人生。

## 7.9 验收

T64：主要组织任职唯一，兼修不错误锁职业。T65：豪侠救援可合法和平完成，成功仍需对象真实到达。T66：同船不能同日在两港运输，容量/船员有效。T67：学生成长消耗双方时间，不能即时复制师傅本领。T68：名士拒绝出仕仍可达职业结局。T69：医馆减免不计收入，医案只用游戏化材料。T70：制造取消守材料归属，名作不是无限随机抽取。T71：阶段结局继续后世界保留，重看不重复领奖。T72：退休有确认，P1无未声明自然寿终。上述后期道路测试随相应版本执行，当前没有声称已实现。
